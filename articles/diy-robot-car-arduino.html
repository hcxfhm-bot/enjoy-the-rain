How to Build a DIY Robot Car with Arduino: Line Following and Obstacle Avoidance

📅 August 15, 2026 ⏱️ 12 min read ✍️ 3D Print Starter Team
🤖

Building an Arduino robot car is one of the most rewarding projects for electronics beginners. Not only do you learn about microcontrollers, sensors, and motor control, but you end up with a functional autonomous vehicle that can navigate its environment. In this comprehensive guide, I'll walk you through building a dual-mode robot that can both follow lines and avoid obstacles.

What You'll Build

This project creates a smart robot car with two autonomous modes:

  • Line Following Mode: The robot uses IR sensors to detect and follow a black line on a white surface
  • Obstacle Avoidance Mode: Using an ultrasonic sensor, the robot detects obstacles and navigates around them

Both modes are perfect for learning fundamental robotics concepts that apply to everything from Roomba vacuums to autonomous vehicles.

Parts List

Here's everything you need to build this project (total cost: approximately $40-60):

Core Components

  • Arduino Uno (or compatible) — The brain of your robot
  • L298N Motor Driver — Controls the DC motors and allows speed/direction control
  • Robot Car Chassis — 2-wheel drive with DC motors and wheels (many kits include this)
  • HC-SR04 Ultrasonic Sensor — For obstacle detection (range: 2-400cm)
  • IR Sensor Modules (x2) — For line detection (usually come in 3-5 packs)
  • Servo Motor (SG90) — Mounts the ultrasonic sensor for scanning

Power and Connections

  • 9V Battery or 2x 18650 Li-ion batteries with holder
  • Breadboard and jumper wires (M-M, M-F, F-F)
  • Switch for power on/off

Pro tip: I recommend buying a complete robot car kit that includes the chassis, motors, wheels, and L298N driver. This saves time sourcing individual parts and ensures compatibility.

How It Works

Before diving into wiring, let's understand the core systems:

Line Following Logic

Two IR sensors mounted at the front detect the contrast between a black line and white surface. When light reflects off a white surface, the sensor outputs HIGH. When it hits a black line (absorbing light), it outputs LOW. By reading both sensors, the Arduino determines:

  • Both sensors HIGH → On white, go straight
  • Left sensor LOW → Line detected on left, turn left
  • Right sensor LOW → Line detected on right, turn right
  • Both sensors LOW → Intersection or end of line, stop or turn

Obstacle Avoidance Logic

The HC-SR04 ultrasonic sensor sends out sound pulses and measures how long they take to bounce back. Using the speed of sound, the Arduino calculates distance to the nearest object. When an obstacle is detected within a threshold (say, 20cm), the robot:

  1. Stops and scans left and right using the servo
  2. Measures distance in both directions
  3. Turns toward the clearer path and continues

Wiring Diagram

Let's wire everything step by step. I recommend building and testing each subsystem separately before combining them.

Step 1: Motor Driver (L298N) Connections

The L298N is your motor controller. Here's how to connect it:

L298N Pin Connect To
ENA (Enable A) Arduino Pin 5 (PWM)
IN1 Arduino Pin 4
IN2 Arduino Pin 3
IN3 Arduino Pin 2
IN4 Arduino Pin 7
ENB (Enable B) Arduino Pin 6 (PWM)
OUT1, OUT2 Left Motor
OUT3, OUT4 Right Motor
12V Battery Positive
GND Battery Negative + Arduino GND

Important: The L298N has a 5V output pin, but I recommend powering the Arduino separately via USB or its own power supply to avoid voltage drops affecting sensor readings.

Step 2: IR Sensors for Line Following

Mount two IR sensors at the front of your robot, spaced about 1.5-2cm apart. Connect each sensor:

  • VCC → Arduino 5V
  • GND → Arduino GND
  • OUT (Left sensor) → Arduino Pin A0
  • OUT (Right sensor) → Arduino Pin A1

Most IR sensor modules have a potentiometer to adjust sensitivity. Start with the module about 1cm above the ground and adjust until it reliably detects your test line.

Step 3: Ultrasonic Sensor (HC-SR04)

For obstacle avoidance:

  • VCC → Arduino 5V
  • GND → Arduino GND
  • TRIG → Arduino Pin 9
  • ECHO → Arduino Pin 10

Mount the sensor on a servo for scanning capability. Connect the servo signal wire to Arduino Pin 11. This lets the robot "look around" when deciding which way to turn.

The Code

Here's the complete Arduino sketch. You can switch between line-following and obstacle-avoidance modes by changing a single variable at the top.

// Robot Car - Line Following + Obstacle Avoidance
// Mode selection: 1 = Line Follow, 2 = Obstacle Avoid
int MODE = 2;

// Motor pins
#define ENA 5
#define IN1 4
#define IN2 3
#define IN3 2
#define IN4 7
#define ENB 6

// IR Sensor pins (Line Following)
#define LEFT_IR A0
#define RIGHT_IR A1

// Ultrasonic Sensor pins
#define TRIG 9
#define ECHO 10

// Servo pin
#define SERVO_PIN 11

// Obstacle distance threshold (cm)
#define OBSTACLE_DIST 20

void setup() {
  // Motor pins as outputs
  pinMode(ENA, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);
  pinMode(ENB, OUTPUT);
  
  // IR sensors as inputs
  pinMode(LEFT_IR, INPUT);
  pinMode(RIGHT_IR, INPUT);
  
  // Ultrasonic sensor
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  
  // Servo
  pinMode(SERVO_PIN, OUTPUT);
  
  Serial.begin(9600);
}

void loop() {
  if (MODE == 1) {
    lineFollow();
  } else {
    obstacleAvoid();
  }
}

// === MOTOR CONTROL FUNCTIONS ===
void moveForward(int speed) {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
  analogWrite(ENA, speed);
  analogWrite(ENB, speed);
}

void turnLeft(int speed) {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
  analogWrite(ENA, speed);
  analogWrite(ENB, speed);
}

void turnRight(int speed) {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, HIGH);
  analogWrite(ENA, speed);
  analogWrite(ENB, speed);
}

void stopMotors() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
}

// === LINE FOLLOWING ===
void lineFollow() {
  int leftVal = digitalRead(LEFT_IR);
  int rightVal = digitalRead(RIGHT_IR);
  
  if (leftVal == HIGH && rightVal == HIGH) {
    // Both on white - go forward
    moveForward(150);
  } else if (leftVal == LOW && rightVal == HIGH) {
    // Line on left - turn left
    turnLeft(100);
  } else if (leftVal == HIGH && rightVal == LOW) {
    // Line on right - turn right
    turnRight(100);
  } else {
    // Both on black - stop
    stopMotors();
  }
}

// === OBSTACLE AVOIDANCE ===
void obstacleAvoid() {
  int distance = getDistance();
  
  if (distance > OBSTACLE_DIST || distance == 0) {
    moveForward(180);
  } else {
    stopMotors();
    delay(500);
    
    // Scan right
    servoWrite(30);
    delay(500);
    int rightDist = getDistance();
    
    // Scan left
    servoWrite(150);
    delay(500);
    int leftDist = getDistance();
    
    // Return to center
    servoWrite(90);
    delay(300);
    
    // Decide direction
    if (leftDist > rightDist) {
      turnLeft(180);
      delay(400);
    } else {
      turnRight(180);
      delay(400);
    }
  }
}

int getDistance() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  
  long duration = pulseIn(ECHO, HIGH);
  int distance = duration * 0.034 / 2;
  return distance;
}

// Simple servo control (no library)
void servoWrite(int angle) {
  int pulse = map(angle, 0, 180, 500, 2400);
  for (int i = 0; i < 20; i++) {
    digitalWrite(SERVO_PIN, HIGH);
    delayMicroseconds(pulse);
    digitalWrite(SERVO_PIN, LOW);
    delayMicroseconds(20000 - pulse);
  }
}

Upload this code to your Arduino using the Arduino IDE. The servo control function is simplified—if you have the Servo library installed, you can replace it with servo.write(angle).

Testing and Calibration

Line Following Calibration

  1. Create a test track using black electrical tape on a white poster board or floor
  2. Start with gentle curves—save sharp turns for later
  3. Adjust the potentiometer on each IR sensor until the indicator LED lights when over white and turns off over black
  4. If the robot wobbles excessively, reduce motor speed in the code

Obstacle Avoidance Calibration

  1. Place objects 30cm in front of the robot and verify it stops
  2. Adjust OBSTACLE_DIST in the code if needed (larger = stops sooner)
  3. Test that the servo scans correctly before deciding direction
  4. If the robot turns the wrong way, swap the turnLeft and turnRight logic

Troubleshooting Common Issues

Problem Solution
Robot moves backward Swap the wires on one or both motors
Motors don't move Check battery voltage; verify L298N jumpers are in place
Line sensor always reads LOW Adjust potentiometer; check wiring; sensors may be too high off ground
Ultrasonic gives 0 distance Check TRIG/ECHO wiring; ensure sensor has clear line of sight
Robot turns circles One motor may be reversed; check IN1-IN4 logic

Conclusion

Building an Arduino robot car teaches you practical skills in electronics, programming, and mechanical design. The line-following mode demonstrates basic sensor integration and logic, while obstacle avoidance introduces decision-making algorithms. Both concepts scale up to advanced robotics and autonomous systems.

Start simple, test often, and don't be afraid to experiment with code modifications. The skills you develop here—reading sensors, controlling motors, making decisions—apply to countless future projects. Happy building!
