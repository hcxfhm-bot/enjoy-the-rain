How to 3D Print Overhangs Without Supports (Tips & Settings)

📅 May 22, 2026 ⏱️ 8 min read ✍️ 3D Print Starter Team
📐

Overhangs are the bane of FDM 3D printing. That 45-degree bridge that looks fine on screen turns into a droopy, stringy mess on your print bed. The default fix? Slap supports everywhere — then spend 30 minutes picking them off, leaving ugly scars on your model.

But here's the thing: most overhang problems aren't caused by the model. They're caused by wrong settings and bad orientation. With the right tweaks, you can print surprisingly steep overhangs without any supports at all.

The 45-Degree Rule (And Why It's Wrong)

Every beginner guide says "keep overhangs under 45 degrees." This comes from a simple geometric fact: at 45°, each layer extends exactly one nozzle-width past the previous layer. The new layer has 50% support from below.

In practice, you can often push well beyond 45° with the right technique. Good printers with strong cooling can handle 55–60° overhangs cleanly. The key is understanding what makes overhangs fail and controlling those variables.

Why Overhangs Fail

Three things kill overhangs:

  1. Gravity — Extruded plastic sags before it solidifies if there's nothing underneath
  2. Insufficient cooling — The filament stays soft too long and droops
  3. Speed — Moving too fast gives the plastic less time to bond to the layer below

Fix all three and overhangs become dramatically better.

5 Tips to Print Better Overhangs Without Supports

1. Max Out Your Cooling Fan

This is the single biggest improvement. Set your part cooling fan to 100% for all overhang layers (and honestly, for most of the print with PLA). The faster the plastic solidifies, the less it sags.

In Cura: Cooling → Fan Speed → Set to 100%
In PrusaSlicer: Cooling → Fan Speed → 255 (max)

Note: This works great for PLA and PETG. For ABS, too much cooling causes layer delamination — you'll need supports instead.

2. Slow Down Overhang Layers

Modern slicers let you set a different speed for overhangs. The idea is simple: print overhang sections slower so the plastic has time to adhere before gravity pulls it down.

Recommended overhang speeds:

  • 0–45° overhang: normal speed (50–60mm/s)
  • 45–55° overhang: 50% speed (25–30mm/s)
  • 55°+ overhang: 30% speed (15–20mm/s)

In Cura: Speed → Overhang Speed → Set per-angle thresholds
In Bambu Studio: Speed → Overhang speed → Set slow-down for overhangs

3. Use Variable Layer Height

Thinner layers mean each overhang step extends less past the previous layer. A 0.12mm layer height overhang looks much cleaner than 0.20mm at the same angle.

Use adaptive/variable layer height to print thin layers only where the overhangs are, and normal layers everywhere else. This keeps print time reasonable. See our best printer settings guide for more on layer height optimization.

4. Rotate the Model

The simplest fix: don't print overhangs at all. Rotate the model so that steep angles face upward instead of outward. A 60° overhang becomes a 30° overhang with a simple 30° rotation.

Things to consider when orienting:

  • Flat faces should touch the build plate
  • Overhangs should face the back of the printer (less airflow turbulence)
  • Important detail faces should point up or sideways — never down

5. Use the Arc Overhang Technique

A clever trick: some slicers (and custom scripts) can print overhangs as concentric arcs instead of straight lines. The curved path is shorter and has more support from adjacent lines. Cura's "Bridge Settings" and PrusaSlicer's overhang detection both use variations of this approach.

Enable Cura → Bridge Settings → Bridge has outline → Enable for better overhang edges.

When You Absolutely Need Supports

Sometimes supports are unavoidable. Flat horizontal surfaces, internal cavities, and anything past 65° overhang on PLA (50° on PETG) needs support material. For a complete guide on when and how to use supports, see our 3D print support settings guide.

To minimize support damage:

  • Use tree/organic supports instead of grid supports (easier removal, less scarring)
  • Set support Z-distance to 0.2mm (creates a gap that makes supports pop off)
  • Use support interface layers for cleaner tops
  • Position supports on non-visible faces whenever possible

Best Slicer Settings for Overhangs

Here's a quick reference for the three major slicers. For a full comparison of these tools, check our Cura vs PrusaSlicer vs Bambu Studio guide.

Cura

  • Cooling → Fan Speed: 100%
  • Speed → Overhang Speed: Enable, set 25mm/s for 45°+
  • Bridge Settings → Enable bridge wall outline: On
  • Support → Support Type: Tree (if needed)

PrusaSlicer

  • Cooling → Fan speed: 255 (max for overhangs)
  • Speed → Overhang speed: Auto-calculated, set multiplier to 0.5
  • Support → Support style: Organic

Bambu Studio

  • Cooling → Part cooling fan: 100% for overhangs
  • Speed → Overhang speed: Enable, slow down to 30%
  • Support → Type: Tree (smooth)

Quick Checklist

Before printing a model with overhangs:

  1. ✅ Check overhang angles in the slicer preview
  2. ✅ Rotate to minimize steep angles
  3. ✅ Set cooling fan to 100%
  4. ✅ Enable overhang speed slow-down
  5. ✅ Consider thinner layer height for overhang sections
  6. ✅ Only add supports where absolutely necessary

Follow these steps and you'll cut your support usage in half — which means faster prints, less waste, and cleaner surfaces.
