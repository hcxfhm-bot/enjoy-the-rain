3D Print G-Code Explained: What Every Line Means

📅 June 1, 2026 ⏱️ 8 min read ✍️ 3D Print Starter Team
📟

Open a G-code file and you'll see hundreds of lines that look like G1 X45.2 Y30.1 E0.0345. It reads like alien language — but it's actually straightforward once you learn a few dozen commands. G-code is the instruction set your 3D printer follows, and understanding it gives you real control over your prints. This guide breaks down every important command, what it does, and when you'll encounter it.

What Is G-Code?

G-code (short for Geometric Code) is a programming language that tells CNC machines — including 3D printers — exactly what to do. Each line is a command: move here, heat that, extrude this much filament. Your slicer (Cura, PrusaSlicer, Orca Slicer) takes your 3D model and converts it into thousands of G-code lines that the printer executes one by one.

Think of it as a recipe. The slicer writes the recipe. The printer follows it step by step. And once you can read the recipe, you can modify it — adjust temperatures on the fly, add pauses, fix errors, and optimize prints in ways the slicer can't.

For a broader overview of how G-code fits into the printing workflow, check out our guide to using G-code with your 3D printer.

How to Read a G-Code Line

Every G-code line follows the same structure:

G1 X45.2 Y30.1 Z0.2 E0.0345 F1200

Here's what each part means:

  • G1 — The command (linear move)
  • X45.2 — Move to X position 45.2mm
  • Y30.1 — Move to Y position 30.1mm
  • Z0.2 — Move to Z height 0.2mm
  • E0.0345 — Extrude 0.0345mm of filament
  • F1200 — Feed rate (speed): 1200mm/min

Not every line has all parameters. A line like G1 X50.0 F900 only moves the X axis at 900mm/min with no extrusion. Parameters that aren't specified keep their last value.

Essential G-Code Commands

G0 and G1 — Movement

G0 is a rapid move (travel without extruding). G1 is a controlled move (usually while extruding). In practice, most slicers use G1 for everything and rely on the E parameter to distinguish printing moves from travel moves. If E is present, filament is being extruded. If E is absent, the nozzle is just repositioning.

G0 X10 Y10 Z5      ; rapid move to (10,10,5), no extrusion
G1 X20 Y10 E0.5 F900 ; controlled move, extrude 0.5mm

G28 — Home All Axes

This command tells the printer to move all axes to their home (zero) position. It's typically the first command in any G-code file — the printer needs to know where it is before it can go anywhere.

G28         ; home all axes
G28 X Y     ; home only X and Y

If your printer has a BLTouch or other probe, G28 also triggers the bed probing sequence. Never skip homing — without it, the printer has no reference point and could crash into the frame.

G29 — Auto Bed Leveling

G29 runs the auto bed leveling probe. The printer measures multiple points on the bed and creates a compensation mesh. This command appears right after G28 in most start G-code scripts.

G28    ; home first
G29    ; then probe the bed

Some printers use M420 S1 instead to load a previously saved mesh, which is faster. If you're using OctoPrint, you can add a G29 plugin to visualize your mesh in real time.

G90 and G91 — Absolute vs. Relative Positioning

G90 sets absolute positioning — all coordinates are relative to the origin. G91 sets relative positioning — coordinates are offsets from the current position.

G90               ; absolute mode (default)
G1 X50 Y50        ; move to position (50,50)
G91               ; relative mode
G1 X10 Y10        ; move 10mm right and 10mm forward from current position

Most of your G-code file uses G90. Relative mode (G91) appears mainly in specific situations like retraction moves or wipe sequences.

M104 and M109 — Hotend Temperature

M104 S200 starts heating the hotend to 200°C but doesn't wait — the next commands execute immediately. M109 S200 heats the hotend and waits until it reaches 200°C before continuing.

M104 S200    ; start heating to 200°C (non-blocking)
M109 S200    ; heat to 200°C and wait (blocking)

Most start scripts use M104 early (so heating begins while the printer is homing), then M109 right before printing starts (to ensure the nozzle is fully up to temperature).

M140 and M190 — Bed Temperature

Same pattern as hotend commands, but for the heated bed. M140 is non-blocking, M190 is blocking.

M140 S60    ; start heating bed to 60°C (non-blocking)
M190 S60    ; heat bed to 60°C and wait (blocking)

Pro tip: Heat the bed first (it takes longer), then start heating the hotend while the bed is still warming. This saves significant time on each print.

M106 and M107 — Fan Control

M106 S255 turns the part cooling fan on at full speed (255 = 100%). M106 S128 sets it to 50%. M107 turns the fan off entirely.

M106 S255    ; fan on at 100%
M106 S128    ; fan on at 50%
M107          ; fan off

Most slicers turn the fan off for the first few layers (better adhesion), then ramp it up for overhangs and bridges. Understanding fan commands helps you tweak cooling for specific filaments — PLA likes full fan, ABS prefers none.

M82 and M83 — Extrusion Mode

M82 sets absolute extrusion — the E value is the total filament extruded since the start. M83 sets relative extrusion — the E value is how much filament to extrude for this move only.

M82         ; absolute extrusion (default in Cura)
M83         ; relative extrusion (default in PrusaSlicer)

This matters when editing G-code by hand. In absolute mode, you need to calculate running totals. In relative mode, each line is self-contained — much easier for manual edits.

G92 — Set Position

G92 tells the printer "consider your current position to be this value." It's most commonly used to reset the extruder counter:

G92 E0    ; reset extruder position to zero

Slicers insert G92 E0 before each layer in absolute extrusion mode, keeping the E values manageable instead of letting them grow into the thousands.

Start G-Code: What Happens Before Your Print

Every G-code file begins with a start script. Here's what a typical one looks like, with annotations:

M140 S60          ; start heating bed
M105              ; report temperature (keeps connection alive)
M190 S60          ; wait for bed to reach 60°C
M104 S200         ; start heating hotend
M109 S200         ; wait for hotend to reach 200°C
G28               ; home all axes
G29               ; auto bed level
G92 E0            ; reset extruder
G1 Z2 F3000       ; raise nozzle 2mm
G1 X0 Y0 F3000    ; move to corner
G1 Z0.2 F500      ; lower to first layer height
G1 X50 E10 F800   ; draw a purge line

This sequence ensures the printer is heated, leveled, and primed before the actual print begins. The purge line at the end ensures filament is flowing — if you see gaps in your first layer, a missing or short purge line could be the culprit.

End G-Code: How Your Print Finishes

M400              ; wait for all moves to finish
M104 S0           ; turn off hotend
M140 S0           ; turn off bed
M106 S0           ; turn off fan
G91               ; relative positioning
G1 Z10 F3000      ; raise nozzle 10mm
G90               ; back to absolute
G1 X0 Y200 F3000  ; move bed forward (easy removal)
M84               ; disable motors

Disabling motors (M84) lets you manually move the print head after the print finishes. Without it, the steppers stay locked and you can't reposition anything.

Common G-Code Modifications

Understanding G-code opens up practical tweaks:

  • Add a pause: Insert M0 or M25 to pause the print — useful for color changes or embedding objects.
  • Change temperature mid-print: Add M104 S210 at a specific layer to increase hotend temperature for better layer adhesion.
  • Slow down overhangs: Some slicers let you add M220 S50 (50% speed) before overhang sections and M220 S100 after.
  • Firmware retract: G10 retracts, G11 unretracts — cleaner than manually editing E values. Learn more in our retraction settings guide.

How to View and Edit G-Code

Any text editor can open a .gcode file — Notepad, VS Code, even your browser. For visualization, use these tools:

  • OctoPrint: Built-in G-code viewer with layer-by-layer navigation.
  • NCViewer: Free online G-code visualizer — drag and drop your file.
  • PrusaSlicer / Orca Slicer: Both show a preview with estimated print time per section.

When editing, always save a copy of the original file. One typo in G-code can cause a crashed print head or a mangled model.

Conclusion

You don't need to memorize every G-code command — most printers use fewer than 20 on a regular basis. Start by understanding G0/G1 (movement), temperature commands (M104/M109/M140/M190), and homing (G28/G29). Those cover 90% of what happens in a typical print file. Once you're comfortable, explore your slicer's start and end G-code settings — that's where the real customization happens.
