How to Build a DIY Smart Door Lock with ESP32 and Home Assistant

📅 June 10, 2026 ⏱️ 8 min read ✍️ 3D Print Starter Team
🔐

Want to upgrade your home security without spending $300 on a commercial smart lock? Building a DIY smart door lock with ESP32 and Home Assistant is easier than you think. In this guide, you'll learn how to create a WiFi-connected door lock that you can control from your phone, automate with Home Assistant, and even integrate with Apple HomeKit.

Why Build a DIY Smart Door Lock?

Commercial smart locks like August, Schlage, or Yale can cost $200-400. They often require proprietary apps, monthly subscriptions, or work only with specific ecosystems. By building your own with ESP32 and Home Assistant, you get:

  • Full control – No cloud dependency, works entirely on your local network
  • Custom integration – Seamlessly works with Home Assistant and other smart home platforms
  • Low cost – Total parts cost under $40
  • Privacy – No data sent to third-party servers
  • Flexibility – Add any feature you want: fingerprint sensor, RFID, keypad, or voice control

Components You'll Need

Before starting, gather these components. Most are available on AliExpress or Amazon for low prices.

Core Components

  • ESP32 Development Board – The brain of the operation. Look for the ESP32-WROOM-32 (around $6-10). It has WiFi, Bluetooth, and enough GPIO pins for our project.
  • Solenoid Lock or Servo Motor – A 12V solenoid lock ($8-15) is the simplest option. For retrofitting existing deadbolts, a high-torque servo like the MG996R ($5-8) works well.
  • Relay Module (5V or 3.3V) – Controls the high-voltage solenoid with low-voltage ESP32 signals. A single-channel relay module costs about $1-2.
  • 12V Power Supply – Solenoid locks typically require 12V. A 2A power supply is sufficient ($8-12).
  • AMS1117-3.3V or Similar Voltage Regulator – Powers the ESP32 from the same 12V supply (optional but recommended).

Optional Upgrades

  • RFID Reader (RC522) – Unlock with RFID cards or key fobs ($2-3)
  • Keypad (4x4 Matrix) – PIN code entry ($3-5)
  • Fingerprint Sensor (AS608) – Biometric unlock ($8-12)
  • Reset Button – Physical override button inside the house ($1)
  • Status LED – Visual feedback for lock/unlock state ($0.50)

Wiring Diagram and Connections

Here's how to wire everything together. Safety first: always disconnect power before making connections!

Basic Wiring (ESP32 + Relay + Solenoid)

ESP32          Relay Module          Solenoid Lock
GPIO 26 -----> IN
5V      -----> VCC
GND     -----> GND

Relay NO (Normally Open) -----> Solenoid Positive
Relay COM (Common)     -----> 12V Power Positive

Solenoid Negative -----> 12V Power Negative
12V Power GND    -----> ESP32 GND (common ground)

Power Supply Setup

The ESP32 runs on 3.3V-5V, while the solenoid needs 12V. You have two options:

  1. Dual Power Supplies – Simplest approach. Use a USB charger for ESP32 and a 12V adapter for the solenoid.
  2. Single 12V Supply + Voltage Regulator – More elegant. Use a buck converter (like LM2596) to step down 12V to 5V for the ESP32.

Flashing ESPHome Firmware

Instead of writing Arduino code from scratch, we'll use ESPHome – a fantastic framework that generates custom firmware from simple YAML configuration. It integrates seamlessly with Home Assistant.

Step 1: Install ESPHome

On your computer with Home Assistant running, install the ESPHome Add-on:

  1. Open Home Assistant → Settings → Add-ons
  2. Search for "ESPHome" and install it
  3. Start the ESPHome dashboard

Step 2: Create New Device

In the ESPHome dashboard:

  1. Click "+ New Device"
  2. Name it "Smart Door Lock"
  3. Select "ESP32" as the device type
  4. Copy the encryption key shown (you'll need it later)

Step 3: Configure the Lock

Edit the device configuration and add this code:

esphome:
  name: smart-door-lock
  friendly_name: Smart Door Lock

esp32:
  board: esp32dev

# Enable logging
logger:

# Enable Home Assistant API
api:
  encryption:
    key: "YOUR_ENCRYPTION_KEY_HERE"

ota:
  password: "YOUR_OTA_PASSWORD"

wifi:
  ssid: "YOUR_WIFI_SSID"
  password: "YOUR_WIFI_PASSWORD"
  ap:
    ssid: "Smart Lock Fallback"
    password: "fallback-password"

# GPIO pin for relay control
switch:
  - platform: gpio
    pin: GPIO26
    name: "Door Lock Relay"
    id: door_lock_relay
    restore_mode: ALWAYS_OFF  # Safety: default to locked

# Optional: Status LED
status_led:
  pin: GPIO2

# Optional: Binary sensor for door status
binary_sensor:
  - platform: gpio
    pin:
      number: GPIO27
      mode: INPUT_PULLUP
      inverted: true
    name: "Door Sensor"
    device_class: door

Step 4: Flash the ESP32

  1. Click "Install" in ESPHome dashboard
  2. Choose "Plug into this computer" for first flash
  3. Connect ESP32 via USB, select the correct port
  4. Wait for flashing to complete (about 2-3 minutes)
  5. ESP32 will restart and connect to your WiFi

Home Assistant Integration

Once flashed, your smart lock will automatically appear in Home Assistant. Here's how to set it up properly:

Adding the Device

  1. Go to Settings → Devices & Services
  2. ESPHome integration should auto-discover "smart-door-lock"
  3. Click "Configure" and enter your encryption key
  4. The lock will appear as a Switch entity

Creating a Lock Template

The ESPHome switch controls the relay, but for proper lock/unlock semantics, create a Template Lock:

lock:
  - platform: template
    name: "Front Door Lock"
    id: front_door_lock
    lock_action:
      - switch.turn_on: door_lock_relay
    unlock_action:
      - switch.turn_off: door_lock_relay
    value_template: "{{ states('switch.door_lock_relay') }}"

This creates a proper lock entity that you can use in automations, dashboards, and even expose to Apple HomeKit.

3D Printing a Custom Case

Now for the fun part – creating a professional enclosure for your smart lock! A 3D printed case protects the electronics and gives your project a polished look.

If you don't have a 3D printer yet, check out our guide on the best 3D printers under $500 to get started with this rewarding hobby.

Case Design Considerations

  • ESP32 mounting – Include standoffs or screw holes for secure mounting
  • Relay module space – Ensure enough clearance for the relay and wiring
  • Wire management – Add strain relief and cable channels
  • Ventilation – The voltage regulator may get warm; add vent holes
  • Mounting options – screw holes for wall mounting or adhesive backing

Where to Find Models

Instead of designing from scratch, check these repositories for existing ESP32 enclosure designs:

  • Thingiverse – Search "ESP32 enclosure" or "ESPHome case"
  • Printables – High-quality, tested designs
  • Cults3D – Unique and specialized enclosures

For a custom fit, use Fusion 360 or Tinkercad to design your own case. Measure your components carefully and add 2-3mm tolerance for easy fitting.

You can also modify existing smart home device cases from our 3D printing smart home cases guide to fit your specific components.

Printing Tips

  • Material – Use PETG for durability and heat resistance (see our PETG vs PLA comparison)
  • Layer height – 0.2mm for strength, 0.15mm for better detail
  • Infill – 20-30% gyroid for a good strength-to-weight ratio
  • Supports – Only if your design has significant overhangs

Automation Ideas

With Home Assistant, the possibilities are endless. Here are some practical automations:

Auto-Lock After Closing

automation:
  - alias: "Auto Lock Door After Closing"
    trigger:
      - platform: state
        entity_id: binary_sensor.door_sensor
        to: "off"  # Door closed
        for: "00:00:30"  # Wait 30 seconds
    action:
      - service: lock.lock
        target:
          entity_id: lock.front_door_lock

Unlock When You Arrive Home

automation:
  - alias: "Unlock When Home"
    trigger:
      - platform: zone
        entity_id: device_tracker.your_phone
        zone: zone.home
        event: enter
    action:
      - service: lock.unlock
        target:
          entity_id: lock.front_door_lock
      - service: notify.mobile_app
        data:
          message: "Welcome home! Door unlocked automatically."

Guest Access with Time Limit

Create a temporary access code that expires:

script:
  grant_temporary_access:
    sequence:
      - service: lock.unlock
        target:
          entity_id: lock.front_door_lock
      - delay: "02:00:00"  # 2 hours
      - service: lock.lock
        target:
          entity_id: lock.front_door_lock

Security Considerations

A smart lock is only as secure as its implementation. Follow these best practices:

Network Security

  • Use WPA3 WiFi encryption (or WPA2 at minimum)
  • Create a separate IoT VLAN for smart home devices
  • Disable UPnP on your router
  • Use strong, unique passwords for ESPHome OTA updates

Physical Security

  • Mount the ESP32 inside the house, not outside
  • Use tamper-proof screws for the enclosure
  • Add a physical key override (don't rely solely on electronics)
  • Install a backup battery (USB power bank) for power outages

Software Security

  • Keep ESPHome firmware updated
  • Use encryption for ESPHome API communication
  • Enable Home Assistant two-factor authentication
  • Regularly review access logs

Troubleshooting Common Issues

ESP32 Won't Connect to WiFi

  • Double-check SSID and password in ESPHome config
  • Ensure 2.4GHz WiFi (ESP32 doesn't support 5GHz)
  • Move ESP32 closer to router for initial setup
  • Check if your WiFi has MAC address filtering enabled

Relay Doesn't Click

  • Verify GPIO pin number in ESPHome config
  • Check relay module requires 3.3V or 5V (most work with both)
  • Test relay independently with a multimeter
  • Ensure common ground between ESP32 and relay power

Home Assistant Doesn't Discover Device

  • Check if ESP32 and Home Assistant are on the same subnet
  • Disable AP mode after initial WiFi connection
  • Manually add device using its IP address
  • Check firewall settings on your router

Taking It Further: Advanced Features

Once you have the basic lock working, consider these upgrades:

Add a Keypad

Connect a 4x4 matrix keypad to ESP32 and program it to unlock when the correct PIN is entered. ESPHome has built-in support for keypad matrix.

RFID Card Access

Add an RC522 RFID reader. Program it to unlock when authorized cards are scanned. Great for family members who don't have smartphones.

Fingerprint Sensor

Connect an AS608 fingerprint sensor for biometric access. ESPHome doesn't have native support, but you can use the UART bus to communicate with the sensor using custom components.

Camera Integration

Add a Raspberry Pi camera to capture photos when someone unlocks the door. Send snapshots to your phone via Home Assistant notifications.

Voice Control

Expose the lock to Google Assistant or Amazon Alexa through Home Assistant cloud or Nabu Casa. Then say, "Hey Google, lock the front door."
