Raspberry Pi Pico Beginner's Guide: Your First RP2040 Project

📅 August 29, 2026 ⏱️ 11 min read ✍️ 3D Print Starter Team
🍓

You've probably heard of the Raspberry Pi — the credit-card-sized computer that runs Linux and powers everything from retro gaming consoles to home servers. But in 2021, the Raspberry Pi Foundation released something very different, and in 2026 it's one of the best $4 you can spend as a maker: the Raspberry Pi Pico.

The Pico is not a tiny computer. It's a microcontroller board built around the Foundation's own RP2040 chip. If you've been wanting to dip into electronics but found full Raspberry Pi projects intimidating, the Pico is the perfect on-ramp. In this guide I'll walk you through exactly what the Pico is, how it differs from the full Raspberry Pi and from Arduino, how to set it up with MicroPython, and how to build your first blinking-LED project in under an hour.

By the end, you'll understand why so many people pair the Pico with their Raspberry Pi DIY projects and electronics workbench as a cheap, power-sipping sidekick for real-world sensors and buttons.

What Exactly Is the Raspberry Pi Pico?

The Raspberry Pi Pico is a small, low-cost development board designed around the RP2040 — a microcontroller chip designed in-house by Raspberry Pi (not by Broadcom, like the full Pi). A microcontroller is a tiny self-contained computer that runs a single program, over and over, with no operating system. It wakes instantly, sips milliwatts, and is perfect for reading sensors, blinking lights, and controlling motors.

Think of it this way: a full Raspberry Pi is a desktop PC that happens to be tiny. The Pico is the chip inside a microwave, a thermostat, or a kids' toy. Both are useful — but they solve completely different problems.

The board itself costs just $4 (the Pico H with pre-soldered headers is $5, and the wireless Pico W is $6). For that price you get:

  • RP2040 chip: Dual-core ARM Cortex-M0+ running at 133 MHz
  • 264 KB of SRAM and 2 MB of onboard QSPI flash (for your program)
  • 26 multi-function GPIO pins (the metal holes you plug wires into)
  • 3 analog inputs via a 12-bit ADC (reads variable voltages from sensors)
  • 2 × UART, 2 × SPI, 2 × I2C for talking to other chips
  • 16 × PWM channels (for dimming LEDs and driving motors)
  • Programmable I/O (PIO) — a unique feature that lets you bit-bang custom protocols in hardware
  • USB 1.1 support (device and host) and a built-in temperature sensor

The standout spec is the dual-core Cortex-M0+ at 133 MHz. Most beginner microcontrollers (like the classic Arduino Uno) run a single core at 16 MHz. The Pico is roughly 8× faster and has two cores to split work between — at a fraction of the price people expected.

Raspberry Pi Pico vs Raspberry Pi vs Arduino

This is the single most confusing part for newcomers, so let's clear it up with a comparison table:

Feature Raspberry Pi Pico Full Raspberry Pi (e.g. Pi 4) Arduino Uno
Type Microcontroller Single-board computer Microcontroller
OS None (runs one program) Linux (Raspberry Pi OS) None (runs one program)
Processor Dual-core 133 MHz Quad-core 1.5 GHz Single-core 16 MHz
RAM 264 KB 2–8 GB 2 KB
Boot time Instant 30–60 seconds Instant
Power draw ~25 mA typical ~600 mA–3 W ~20 mA
Wi-Fi Only on Pico W Built-in None (add-on needed)
Price $4 $35–75 $20–25

So when do you reach for the Pico? Use it for physical computing — reading a button, blinking an LED, controlling a relay, logging a temperature sensor — especially when you want it to run for months on batteries or start instantly. Use a full Raspberry Pi when you need a desktop, a browser, or to run Home Assistant. The Pico slots neatly between the full Pi and the Arduino Uno: faster and cheaper than an Uno, but just as simple to program.

If you're coming from the ESP32 world, the Pico is a very similar class of device. The ESP32 adds built-in Wi-Fi and Bluetooth on every board (vs only the Pico W), while the Pico's PIO and C/C++ SDK are often considered more beginner-friendly. Both are excellent; pick based on whether you need wireless out of the box.

What You Need to Get Started

The beauty of the Pico is how little you need. Here's the minimum shopping list:

  • Raspberry Pi Pico (or Pico H) — $4–5. Get the Pico H if you don't want to solder; the headers are pre-attached.
  • A micro-USB cable — the data kind, not a charge-only cable. This both powers the board and uploads your code.
  • An LED and a 330Ω resistor — for your first project.
  • Some jumper wires and a breadboard — to connect things without soldering. A proper workbench layout makes this far less fiddly.
  • A computer (Windows, macOS, or Linux) running the free Thonny IDE.

Optional but recommended for later: a push button, a few sensors (temperature, light), and a bench power supply if you move beyond USB power. You do not need a separate programmer or a wall adapter — the Pico is powered straight from your computer's USB port.

Step 1: Install Thonny and Flash MicroPython

The Pico can be programmed in C/C++ or MicroPython. For beginners, MicroPython is the way to go — it's Python trimmed down for microcontrollers, so the code reads almost like plain English. The easiest editor is Thonny, a free Python IDE with first-class Pico support.

  1. Download and install Thonny from thonny.org (Windows, macOS, Linux all supported).
  2. Hold down the BOOTSEL button on the Pico, then plug in the micro-USB cable. Keep BOOTSEL held until the board appears as a USB drive called "RPI-RP2".
  3. In Thonny, open Run → Configure interpreter, choose "MicroPython (Raspberry Pi Pico)" as the interpreter, and click "Install or update MicroPython (Raspberry Pi Pico)".
  4. Select the downloaded UF2 firmware file (or let Thonny fetch it), pick the RPI-RP2 target, and click Install. The board reboots and is now running MicroPython.
  5. Unplug and replug the Pico normally (no BOOTSEL this time). In Thonny's bottom shell, you should see a >>> prompt — that's your Pico talking to you.

That's it. No drivers, no command line, no compiling toolchains. If you've ever been put off by Arduino's setup, the Pico + Thonny experience is noticeably smoother.

Step 2: Your First Project — Blinking an LED

No electronics guide is complete without the "hello world" of hardware: the blinking LED. Let's wire it and code it.

Wiring

  • Connect the LED's long leg (anode) to a 330Ω resistor, then to Pico GP15.
  • Connect the LED's short leg (cathode) to a GND pin on the Pico.
  • Plug the Pico into USB. The LED won't light yet — you have to tell it to.

The Code

In Thonny, type the following and click the green "Run" button:

from machine import Pin
import time

led = Pin(15, Pin.OUT)  # GP15 as output

while True:
    led.value(1)   # LED on
    time.sleep(1)  # wait 1 second
    led.value(0)   # LED off
    time.sleep(1)  # wait 1 second

Your LED should now blink once per second. Congratulations — that's your first RP2040 project. The key ideas to absorb: Pin(15, Pin.OUT) tells the chip that GP15 is an output, and led.value(1) / led.value(0) turn it high (3.3V) or low (0V).

Step 3: Add a Button (Reading Input)

Blinking is fun, but the real power of a microcontroller is reacting to the world. Let's add a button so the LED only lights when you press it.

  • Connect one leg of a push button to GP14 and the other leg to GND.
  • Add a Pin(14, Pin.IN, Pin.PULL_UP) line so the pin reads "high" by default and "low" when the button grounds it.
from machine import Pin

led = Pin(15, Pin.OUT)
button = Pin(14, Pin.IN, Pin.PULL_UP)

while True:
    if button.value() == 0:   # button pressed (pulled to GND)
        led.value(1)
    else:
        led.value(0)

Now the LED follows your finger. From here, swapping the button for a sensor (light, temperature, motion) is a small change — and that's exactly how people build their first smart plant monitor or weather logger.

The Pico W: Adding Wi-Fi and Smart Home Powers

The standard Pico has no wireless radio. If your project needs to talk to the internet or your home network, you want the Raspberry Pi Pico W ($6). It adds an Infineon CYW43439 chip for Wi-Fi (and Bluetooth 5.0 on newer revisions), and the MicroPython code is nearly identical — you just import a network module to join your Wi-Fi.

Why does that matter? Because a Pico W can publish sensor readings to Home Assistant, act as a low-cost temperature node, or even serve a tiny web page. It's a fantastic, dirt-cheap alternative to an ESP32 when you don't already have one on hand. For battery-powered, always-on gadgets, the Pico's ~25 mA draw (and even lower in deep sleep) means it can run for a long time on a small cell.

If you go the smart-home route, you can also run the Pico under ESPHome-style firmware or push readings over MQTT — the same plumbing the rest of your maker network uses.

5 Common Beginner Mistakes (and How to Avoid Them)

  • Using a charge-only USB cable. Some phone cables carry power but no data, so your code never uploads. If Thonny can't see the Pico, swap the cable first.
  • Forgetting the current-limiting resistor. An LED with no resistor will pull too much current and can burn out the pin. Always use 220–330Ω.
  • Confusing GP numbers with physical pin numbers. On the Pico, Pin(15) is GP15 — not the 15th physical pin. Check the pinout diagram; GP labels are what your code uses.
  • Skipping BOOTSEL on first flash. The very first time you load MicroPython, you must hold BOOTSEL while plugging in. After that, normal plugging works.
  • Drawing too much from the 3V3 pin. The Pico's 3.3V regulator can supply roughly 300 mA. Motors and many relays need a separate power supply or a relay module driven by the pin, not powered through it.

FAQ

Q: Is the Raspberry Pi Pico the same as a Raspberry Pi?
A: No. The full Raspberry Pi is a single-board computer that runs Linux; the Pico is a microcontroller that runs one program with no OS. They complement each other rather than compete.

Q: Do I need to know Python already?
A: Not really. MicroPython is beginner-friendly, and the examples above are copy-pasteable. If you can read "turn the LED on, wait, turn it off," you can program a Pico.

Q: Can the Pico replace an Arduino Uno?
A: For most beginner projects, yes — and it's faster and cheaper. The main reason to stick with an Uno is existing shields or tutorials written specifically for the Uno's ATmega chip. See our Arduino vs Raspberry Pi comparison for the bigger picture.

Q: Can I use the Pico without soldering?
A: Yes — buy the Pico H (pre-soldered headers) and use a breadboard with jumper wires. No iron required for your first dozen projects.

Q: How do I power the Pico away from a computer?
A: Supply 1.8–5.5V to the VSYS pin (e.g., from a USB power bank, 3× AA batteries, or a LiPo through a regulator). The onboard regulator handles the rest.

Conclusion

The Raspberry Pi Pico is the friendliest, cheapest entry point into physical computing we've seen in years. For $4 you get a dual-core 133 MHz chip, 26 GPIO pins, and a polish-free setup that gets a beginner from "unboxed" to "blinking LED" in under an hour. Whether you're building your first button-triggered gadget, a battery-powered sensor, or a Wi-Fi node for your smart home, the RP2040 is more than capable.

Start with MicroPython and Thonny, build the blink, then add a button, then a sensor. Before long you'll be wondering why you ever thought microcontrollers were scary. Grab a Pico (or a Pico W if you want wireless), set up your workbench, and start making.
