Klipper Input Shaping: How to Eliminate Ringing for Good

📅 June 1, 2026⏱️ 8 min read✍️ 3D Print Starter Team
📐

Input shaping is the single biggest quality improvement you can make to a Klipper printer. It eliminates ringing/ghosting by pre-distorting the movement commands to cancel out the printer's natural vibrations. Here's how to set it up properly.

What You Need

  • Klipper installed and working
  • ADXL345 accelerometer (~$5 from Amazon/AliExpress)
  • Wiring: SPI connection to Raspberry Pi GPIO

ADXL345 Wiring

ADXL345 PinRaspberry Pi GPIO
VCC3.3V (Pin 1)
GNDGND (Pin 6)
CSGPIO8 (Pin 24)
SDOGPIO9 (Pin 21)
SDAGPIO10 (Pin 19)
SCLGPIO11 (Pin 23)

Calibration Steps

  1. Mount the accelerometer on the print head with double-sided tape or a printed mount
  2. Add to printer.cfg: [adxl345] section with SPI configuration
  3. Test connection: ACCELEROMETER_QUERY
  4. Run calibration: SHAPER_CALIBRATE
  5. Save results: SAVE_CONFIG

Understanding the Results

Klipper will recommend a shaper type and frequency. Common recommendations:

  • EI shaper at 50-60 Hz — Good balance of damping and speed
  • MZV shaper at 40-50 Hz — Stronger damping, slightly more speed reduction
  • ZV shaper at 60+ Hz — Minimal speed impact, less damping
