Why Build a Smart Plant Monitor?

If you've ever killed a houseplant by forgetting to water it — or the opposite, drowning it with love — you know the struggle. Commercial smart plant sensors exist (think Xiaomi Mi Flora, Parrot Flower Power), but they cost $30–50 per plant and lock you into their app. For a home with 10 plants, that's $300–500.

Building your own smart plant monitor with an ESP32, soil moisture sensors, and Home Assistant costs under $10 per plant. You get real-time data on moisture, temperature, and light levels — all in one dashboard, fully customizable, and with no subscription fees.

This guide walks you through building a multi-sensor plant monitor that works with Home Assistant, sends push notifications when your plants are thirsty, and even triggers automated watering via a relay module.

How Smart Plant Monitoring Works

A smart plant monitor is a simple sensor network. At minimum, you need a soil moisture sensor. The more advanced version adds temperature, light, and fertilizer (EC) sensors. All sensors connect to a microcontroller (ESP32) that reads the values and transmits them to Home Assistant via WiFi.

The signal chain looks like this:

Soil Moisture Sensor → ESP32 → WiFi → Home Assistant → Dashboard / Automations

Once in Home Assistant, you can:

  • View all plants on a single dashboard
  • Get notified when moisture drops below a threshold
  • Trigger a watering pump via relay module
  • Log historical data to spot trends
  • Trigger automations based on time of day, season, or weather

Soil Moisture Sensor Types: Resistive vs. Capacitive

This is the most important hardware decision you'll make. Resistive sensors are cheap but corrode within weeks when left in moist soil continuously. Capacitive sensors use a different measurement principle — they don't have exposed electrodes, so they last months or even years.

💡 Key Recommendation

Always choose capacitive sensors (like the v1.2 or v2.0 boards). Resistive sensors (the cheap red PCB kind) are fine for experiments but will give you false readings after 2–4 weeks of continuous use.

The popular capacitive sensors are:

  • Capacitive Soil Moisture v1.2 — Analog output (0–3.3V), simple, reliable
  • Capacitive Soil Moisture v2.0 — I2C interface, more stable readings, slightly more expensive
  • Xiaomi JL-BC-01 — Bluetooth, battery-powered, but easily hacked for ESPHome integration
  • EZO by Atlas Scientific — Laboratory-grade, overkill for houseplants but excellent for garden monitoring

ESP32 Setup with ESPHome

We'll use ESPHome to program the ESP32 — it's the easiest way to integrate with Home Assistant, requires zero cloud services, and runs entirely locally. If you haven't set up ESPHome yet, follow our ESP32 Smart Home Projects guide first.

Create a new ESPHome device in Home Assistant (Settings → Add-ons → ESPHome → Open Web UI). Add this configuration for a basic 3-sensor plant monitor:

esphome:
  name: plant-monitor-1
  platform: ESP32
  board: esp32dev

wifi:
  ssid: "YOUR_WIFI_SSID"
  password: "YOUR_WIFI_PASSWORD"

api:
  password: "ESPHOME_API_PASSWORD"

ota:
  password: "OTA_PASSWORD"

sensor:
  - platform: adc
    pin: GPIO34
    name: "Plant 1 Moisture"
    unit_of_measurement: "%"
    accuracy_decimals: 0
    filters:
      - calibrate_linear:
          - 0.0 -> 100.0   # dry
          - 3.3 -> 0.0     # wet (sensor output vs real moisture)
    update_interval: 5min

  - platform: dht
    pin: GPIO27
    model: DHT22
    temperature:
      name: "Plant 1 Temperature"
    humidity:
      name: "Plant 1 Humidity"
    update_interval: 5min

  - platform: bh1750
    pin: GPIO21
    name: "Plant 1 Light"
    address: 0x23
    update_interval: 10min

The calibration values (calibrate_linear) are the most important part. Put the sensor in dry soil, note the reading, then put it in water-saturated soil, and adjust the numbers accordingly. Each sensor batch is slightly different.

Wiring the Sensors

Here's how to wire everything for a complete multi-sensor plant monitor:

ESP32 → Capacitive Soil Moisture Sensor:

  • Sensor VCC → ESP32 3.3V (or 5V for v1.2 sensors)
  • Sensor GND → ESP32 GND
  • Sensor AOUT → ESP32 GPIO34 (ADC pin)

ESP32 → DS18B20 (Temperature):

  • DS18B20 Red (VCC) → ESP32 3.3V via 4.7K resistor
  • DS18B20 Black (GND) → ESP32 GND
  • DS18B20 Yellow (Data) → ESP32 GPIO27 + 4.7K pull-up resistor

ESP32 → BH1750 (Light Sensor):

  • BH1750 VCC → ESP32 3.3V
  • BH1750 GND → ESP32 GND
  • BH1750 SDA → ESP32 GPIO21
  • BH1750 SCL → ESP32 GPIO22

For the waterproof DS18B20 probe, you'll need to add the one_wire component to ESPHome and enable the GPIO pin you used. For wiring multiple capacitive sensors, just use different ADC pins (GPIO34, GPIO35, GPIO36, GPIO39).

Connecting to Home Assistant

Once ESPHome compiles and flashes your firmware, the ESP32 will automatically appear in Home Assistant as a new device under Settings → Devices. All your sensors will be there, ready to add to your dashboard.

For a cleaner setup, use Home Assistant's Helpers (Settings → Devices & Services → Helpers) to create threshold sensors:

# Example: Binary sensor that turns ON when soil is dry
template:
  - binary_sensor:
      - name: "Plant 1 Needs Water"
        state: "{{ states('sensor.plant_1_moisture') | float(50) < 30 }}"
        icon: mdi:water-alert

This creates a virtual sensor that changes to "on" when moisture drops below 30%. You can then use this in automations to send alerts.

Building a Plant Monitoring Dashboard

Home Assistant makes it easy to create a beautiful plant dashboard. Add a new Dashboard in Home Assistant and add these cards:

  • Gauge cards — For moisture percentage, temperature, and light level
  • Mini graph card — Shows 24-hour or 7-day history of moisture levels
  • Picture elements card — Place sensor values over a photo of each plant
  • Conditional card — Shows an alert icon only when a plant needs attention

Set each plant's thresholds based on its species. Succulents and cacti prefer 10–20% moisture most of the time. Tropical plants like peace lilies thrive at 40–60%. Herbs in the kitchen window are happy at 30–50%. You'll calibrate these numbers over a few weeks as you learn each plant's watering rhythm.

Automations: Alerts and Watering Actions

The real value of a smart plant monitor is automation. Here are the automations that make it genuinely useful:

Automation 1: Push Notification When Plant is Dry

automation:
  - alias: "Notify: Plant needs water"
    trigger:
      - platform: numeric_state
        entity_id: sensor.plant_1_moisture
        below: 25
    condition:
      - condition: time
        after: "07:00:00"
        before: "21:00:00"
    action:
      - service: notify.mobile_app_your_phone
        data:
          title: "💧 Plant Alert"
          message: "Plant 1 (Monstera) needs water! Current moisture: {{ states('sensor.plant_1_moisture') }}%"

Automation 2: Auto-Watering with Relay Module

Connect a 5V relay module to the ESP32 and a 12V water pump. When moisture drops below 20%, the relay closes, the pump runs for 30 seconds, and moisture is checked again in 10 minutes.

automation:
  - alias: "Auto-water Plant 1"
    trigger:
      - platform: numeric_state
        entity_id: sensor.plant_1_moisture
        below: 20
    condition:
      - condition: state
        entity_id: input_boolean.plant_1_auto_water
        state: "on"
    action:
      - service: switch.turn_on
        entity_id: switch.plant_1_water_pump
      - delay:
          seconds: 30
      - service: switch.turn_off
        entity_id: switch.plant_1_water_pump

The input_boolean lets you enable or disable auto-watering without editing automations. Add it as a toggle on your dashboard.

3D Printing a Custom Sensor Enclosure

Once your electronics are working, you'll want a proper enclosure to protect them. The sensor probe goes into the soil, but the ESP32 and wiring need protection from moisture, dust, and accidental spills.

We've designed a 3D-printable smart home sensor enclosure that works great for plant monitors. Key features:

  • Wall-mountable or stake-style for pushing into soil
  • Cutouts for USB power cable
  • Slots for routing sensor wires cleanly
  • Snap-fit lid for easy battery access

Print settings: PLA or PETG, 0.2mm layer height, 15% infill, no supports needed for most designs. PETG is preferred since it handles humidity better than PLA over long periods.

Troubleshooting Common Issues

Sensor Readings Stuck at Same Value

This usually means the sensor has corroded (if resistive) or there's a wiring issue. For capacitive sensors, check that the wire between the probe and the amplifier board isn't broken. Wiggle the wires gently while watching the reading — any fluctuation indicates a loose connection.

ESP32 Goes Offline

If your ESP32 drops off WiFi frequently, the most common cause is insufficient power. The ESP32 can draw 250mA+ during WiFi transmission. If you're using a weak USB power source or long USB cable with voltage drop, the board will reset. Use a dedicated 5V/2A power supply and keep cables short.

Moisture Readings Don't Match Reality

Recalibrate. The raw ADC values from capacitive sensors don't map linearly to "percent moisture" across all soil types. Sandy soil reads differently from potting mix. Create custom calibration curves for each plant's pot if you need accuracy. Our Electronics Sensor Guide covers calibration techniques in detail.

Battery-Powered Node Drains Quickly

Deep sleep is essential. Configure ESPHome to sleep between readings:

deep_sleep:
  run_duration: 30s
  sleep_duration: 10min

With deep sleep, a 2000mAh LiPo battery can power a plant monitor for 6–12 months. Without it, expect 3–5 days at most.

Frequently Asked Questions

Can I use this outdoors for garden monitoring?

Absolutely. For garden beds, you'll want IP65+ rated enclosures, weatherproof sensor probes, and possibly solar charging. This project pairs perfectly with our DIY Weather Station guide — share the data to correlate plant stress with weather patterns.

How accurate are cheap capacitive sensors?

Good enough for watering decisions. They won't give you laboratory-precise readings, but they'll reliably tell you "dry" vs "wet" and track trends over time. For research-grade data, use EZO sensors or similar.

Can I integrate with Apple HomeKit?

Yes. If you use Home Assistant with the HomeKit Bridge integration, all your plant sensors appear natively in Apple Home app and can trigger Siri Shortcuts for plant care reminders.

What's the best plant species for smart monitoring?

Start with your most finicky plants. Plants that are dramatic about watering — like Monsteras, Peace Lilies, or Calatheas — are the ones where real-time data actually changes your behavior. The plant monitor becomes most valuable when it tells you something you couldn't easily guess by looking.

Can I power multiple sensors from one ESP32?

Yes. ESP32 has multiple ADC pins. With careful wiring, you can monitor up to 6–8 capacitive sensors from one board using a manual multiplexing approach, or use an I2C multiplexer (like the TCA9548A) to connect multiple I2C sensors.
