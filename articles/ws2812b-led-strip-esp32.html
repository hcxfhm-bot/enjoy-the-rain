How to Control WS2812B LED Strips with ESP32: FastLED and WLED Guide

📅 June 29, 2026 ⏱️ 20 min read ✍️ 3D Print Starter Team
💡

WS2812B LED strips (also known as NeoPixels) are the holy grail of DIY lighting. Unlike old-school LED strips where every LED is the same color, each WS2812B LED is individually addressable — meaning you can control 144, 288, or even 1000+ LEDs independently, creating rainbow waves, music-reactive effects, and ambient lighting that looks like it came from a sci-fi movie.

And the best part? An ESP32 board can control these strips over WiFi. That means you can change colors from your phone, integrate with Home Assistant, or sync with Spotify — all for under $20 in parts.

In this guide, I'll walk you through two approaches: the FastLED library (for custom code and effects) and WLED (a ready-to-flash firmware with 100+ built-in effects). By the end, you'll have a fully controllable LED setup that rivals commercial smart lights at a fraction of the cost.

What Are WS2812B LEDs?

WS2812B is the technical name for what Adafruit calls "NeoPixel." Each LED has a tiny built-in controller chip that receives data, shows its color, and passes the rest of the data to the next LED. This creates a daisy-chain where one data wire controls everything.

Key specs:

  • Voltage: 5V (most common) — do NOT connect directly to 12V!
  • Current: Up to 60mA per LED at full white (30 LEDs = 1.8A max)
  • Data speed: 800kHz — fast enough for smooth animations
  • Density: 30, 60, 144 LEDs per meter (higher = brighter, more power)

For ESP32 projects, a 30-LED/meter strip is perfect — bright enough for under-cabinet lighting, PC case lighting, or a DIY Ambilight without needing a massive power supply.

What You'll Need

Here's your shopping list for a complete ESP32 + WS2812B setup:

  • 1 × ESP32 DevKit V1 — Any ESP32 board works. I recommend the DevKitC or NodeMCU-32S for easy breadboard use.
  • 1 × WS2812B LED strip — 30 LEDs/meter (1m strip = 30 LEDs) is a good start.
  • 1 × 5V power supply — At least 2A (10W) for 30 LEDs at full brightness. A USB phone charger works for short strips.
  • 1 × 470Ω resistor — Protects the data line (optional but recommended).
  • 1 × 1000µF capacitor — Smooths power spikes (optional but prevents flickering).
  • Jumper wires and breadboard — For prototyping.
  • Micro USB cable — To flash the ESP32.

Method 1: FastLED Library (Custom Code Approach)

FastLED is the most popular Arduino library for addressable LEDs. It gives you complete control over every LED, with functions for rainbows, fades, and patterns — but you write the code yourself.

Step 1: Install FastLED in Arduino IDE

  1. Open Arduino IDE
  2. Go to Sketch → Include Library → Manage Libraries
  3. Search for "FastLED"
  4. Click Install

Step 2: Wire the LED Strip to ESP32

WS2812B strips have three wires: 5V, GND, and Data In (DI). Here's how to connect:

  • 5V on strip → 5V power supply positive (or ESP32 5V pin if using USB power)
  • GND on strip → Power supply GND and ESP32 GND (must share ground!)
  • Data In (DI) → ESP32 GPIO pin (e.g., GPIO 16) through a 470Ω resistor

Important: Always connect GND first! A floating ground can damage the LEDs.

Step 3: Upload the Code

Here's a minimal FastLED sketch that creates a rainbow cycle:

#include <FastLED.h>

#define LED_PIN     16
#define NUM_LEDS    30
#define BRIGHTNESS  64
#define LED_TYPE    WS2812B
#define COLOR_ORDER GRB

CRGB leds[NUM_LEDS];

void setup() {
  FastLED.addLeds<LED_TYPE, LED_PIN, COLOR_ORDER>(leds, NUM_LEDS);
  FastLED.setBrightness(BRIGHTNESS);
}

void loop() {
  fill_rainbow(leds, NUM_LEDS, 0, 255/NUM_LEDS);
  FastLED.show();
  delay(50);
}

Upload this to your ESP32, and you'll see a rainbow wave moving across the strip. Change NUM_LEDS to match your strip length, and adjust BRIGHTNESS (0-255) to control intensity.

Step 4: Add WiFi Control (Basic)

To make this smart, you need WiFi. Here's a simple web server that lets you change colors from your phone:

#include <WiFi.h>
#include <FastLED.h>
#include <WebServer.h>

const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_WIFI_PASSWORD";

#define LED_PIN 16
#define NUM_LEDS 30

CRGB leds[NUM_LEDS];
WebServer server(80);

void handleRoot() {
  String html = "<h1>LED Control</h1>";
  html += "<a href='/red'>Red</a><br>";
  html += "<a href='/green'>Green</a><br>";
  html += "<a href='/blue'>Blue</a><br>";
  html += "<a href='/rainbow'>Rainbow</a><br>";
  html += "<a href='/off'>Off</a>";
  server.send(200, "text/html", html);
}

void handleRed() {
  fill_solid(leds, NUM_LEDS, CRGB::Red);
  FastLED.show();
  server.send(200, "text/plain", "Red!");
}

void handleGreen() {
  fill_solid(leds, NUM_LEDS, CRGB::Green);
  FastLED.show();
  server.send(200, "text/plain", "Green!");
}

void handleBlue() {
  fill_solid(leds, NUM_LEDS, CRGB::Blue);
  FastLED.show();
  server.send(200, "text/plain", "Blue!");
}

void handleRainbow() {
  fill_rainbow(leds, NUM_LEDS, 0, 255/NUM_LEDS);
  FastLED.show();
  server.send(200, "text/plain", "Rainbow!");
}

void handleOff() {
  FastLED.clear();
  FastLED.show();
  server.send(200, "text/plain", "Off!");
}

void setup() {
  FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) delay(500);

  server.on("/", handleRoot);
  server.on("/red", handleRed);
  server.on("/green", handleGreen);
  server.on("/blue", handleBlue);
  server.on("/rainbow", handleRainbow);
  server.on("/off", handleOff);
  server.begin();
}

void loop() {
  server.handleClient();
}

After uploading, open the Serial Monitor (115200 baud) to see the ESP32's IP address. Type that into your phone's browser, and you'll get a simple control page.

Method 2: WLED Firmware (No-Code Solution)

If writing code isn't your thing, WLED is a pre-made firmware that turns your ESP32 into a commercial-grade LED controller. It includes:

  • 100+ built-in effects (rainbow, fire, twinkle, meteor, etc.)
  • Web interface accessible from any device
  • Native Home Assistant integration via MQTT
  • Sync with music, Alexa, and Spotify
  • Schedules and timers

Step 1: Flash WLED

The easiest way is using the WLED Web Installer (no software needed!):

  1. Go to https://install.wled.me in Chrome or Edge
  2. Connect your ESP32 to your computer via USB
  3. Click Connect and select the ESP32's COM port
  4. Click Install WLED and wait for the flash to complete
  5. Connect to the "WLED-AP" WiFi network from your phone
  6. Open http://4.3.2.1 in your browser to configure WiFi

Step 2: Configure LED Settings

Once WLED is running, go to Config → LED Preferences:

  • LED count: Enter your strip's LED count (e.g., 30)
  • GPIO: Set to the pin you connected Data In (default is GPIO 16)
  • LED type: WS281x
  • Color order: GRB (most WS2812B strips)

Save, and your LEDs should light up with the default effect!

Step 3: Explore the Web Interface

WLED's interface is incredibly polished. From the main screen, you can:

  • Colors: Pick solid colors or color palettes
  • Effects: Scroll through 100+ effects with live preview
  • Segments: Split the strip into zones (e.g., left/right)
  • Presets: Save favorite combinations for one-tap access
  • Timers: Schedule lights on/off at specific times

Step 4: Integrate with Home Assistant

WLED integrates natively with Home Assistant. If you've set up a Home Assistant hub on Raspberry Pi, it will auto-discover your WLED device once both are on the same network.

In Home Assistant:

  1. Go to Settings → Devices & Services
  2. Look for "WLED" under discovered integrations
  3. Click Configure and enter the WLED device's IP
  4. Now you can control brightness, effects, and colors from HA dashboards and automations

Power Management: Don't Burn Your House Down

Addressable LEDs can draw a lot of current. A 30-LED strip at full white needs 1.8A — more than USB can safely provide. Here's how to power properly:

For Small Projects (≤30 LEDs)

You can power from the ESP32's 5V pin if using a strong USB adapter (2A+). But avoid full-white for long periods.

For Medium Projects (30-100 LEDs)

Use a dedicated 5V 3-5A power supply. Connect directly to the LED strip's power wires, not through the ESP32.

For Large Projects (100+ LEDs)

Use a 5V 10A+ power supply and inject power at both ends of the strip. Voltage drop causes color inconsistency and flickering.

Always use a multimeter to verify voltage before connecting expensive LED strips. A 12V power supply will instantly kill a 5V WS2812B strip!

Troubleshooting Common Issues

LEDs flicker or show random colors

Cause: Power supply can't deliver enough current, or voltage drop along the strip.

Fix: Use a stronger power supply, inject power at both ends, and add a 1000µF capacitor across 5V/GND.

Only the first few LEDs light up

Cause: Wrong LED count in code, or data line disconnected after first LED.

Fix: Check your NUM_LEDS value and verify the strip isn't damaged (try a different section).

LEDs stay off but code uploads successfully

Cause: Wrong GPIO pin in code, or wrong color order (RGB vs GRB).

Fix: Double-check the pin number in your code matches the physical connection. Try changing COLOR_ORDER to RGB.

WLED won't connect to WiFi

Cause: Wrong password, or 2.4GHz/5GHz confusion (ESP32 only supports 2.4GHz).

Fix: Reset WLED by unplugging and plugging 5 times quickly, then reconfigure WiFi.
