DIY Smart Light Dimmer with Arduino and TRIAC: Custom Dimmer Control (2026)

📅 July 17, 2026 ⏱️ 14 min read ✍️ 3D Print Starter Team
💡

Commercial smart dimmers work well, but they lock you into a specific ecosystem, limit your control options, and often can't handle unusual load types. If you want full control over your dimming logic — or just want to learn how AC dimming actually works — building your own TRIAC-based dimmer with an Arduino or ESP32 is one of the most rewarding maker projects you can tackle.

In this guide, you'll learn how AC dimming works at the circuit level, how to detect zero-crossing for precise timing, and how to build a fully functional smart dimmer you can control via serial, web interface, or integrate directly into Home Assistant.

What Is TRIAC Dimming and How Does It Work?

A TRIAC (Triode for Alternating Current) is a semiconductor device that acts like a switch for AC circuits. Unlike a relay that is either fully on or fully off, a TRIAC can be triggered partway through each AC half-cycle — allowing you to control the average power delivered to a load.

Here's the key concept: mains AC oscillates at 50Hz or 60Hz, crossing through zero voltage 100 or 120 times per second. By triggering the TRIAC at a specific delay after each zero-crossing, you control what percentage of each AC wave reaches your light bulb. Trigger early → full brightness. Trigger late → dim. No trigger → light off.

This technique is called phase-angle dimming, and it's exactly how wall dimmer switches, lamp dimmers, and motor speed controllers all work under the hood.

Components You Need

Here's the full parts list for a safe, functional TRIAC dimmer:

  • Arduino Uno / Nano or ESP32 — your controller of choice
  • TRIAC — BT138-600 or BTA16-600 — rated for 16A, 600V, handles most residential loads
  • Zero-cross detection module — H11AA1 or 4N25 optocoupler — detects AC zero-crossing point
  • MOC3021 or MOC3023 optocoupler — isolates your microcontroller from the high-voltage AC side
  • Resistors — 10kΩ, 330Ω, 470Ω — voltage division and current limiting
  • Capacitor — 100nF / 275V — snubber for TRIAC protection
  • Prototyping board or custom PCB
  • Enclosure — ideally 3D printed, see below
  • Terminal blocks — for AC mains and load connections

⚠️ Safety note: This project involves mains voltage (120V/240V AC). Never work on the AC side of the circuit while it's live. Build in a proper enclosure, use correct gauge wiring for the current, and always double-check your wiring before applying power. If you're uncomfortable working with mains voltage, consider using a 12V DC dimmer circuit instead.

Understanding the Zero-Cross Detection Circuit

The zero-cross detection circuit is what makes precise dimming possible. The optocoupler produces a pulse every time the AC waveform crosses zero, which your Arduino uses as a timing reference. Without this, you'd be triggering the TRIAC blind.

The typical circuit uses a full-wave bridge rectifier feeding the optocoupler's LED. The output goes HIGH when AC crosses zero and LOW during the rest of the cycle. Your code measures the time between zero-crossings to calculate the correct firing delay for your desired brightness level.

For a 50Hz AC supply, the full cycle is 20ms. For 60Hz, it's 16.67ms. The delay after zero-crossing controls brightness:

  • 0ms delay → full wave → 100% brightness
  • 5ms delay (50Hz) / 4.17ms (60Hz) → half wave → 50% brightness
  • Near full delay → barely any wave → barely any light

Building the Dimmer Circuit

Here's the complete circuit connection diagram:

Zero-cross detection branch: Connect mains Live through a 10kΩ resistor to the anode of the optocoupler LED. Connect the cathode to Neutral. The optocoupler's transistor output connects between Arduino pin 2 (or any interrupt-capable pin) and Ground, with a 10kΩ pull-up to 5V.

TRIAC gate control: Connect Arduino pin 3 (or any PWM-capable pin) through a 330Ω resistor to pin 1 (anode) of the MOC3021 optocoupler. Connect pin 2 (cathode) to Ground. The MOC3021's output (pins 4 and 6) connects to the TRIAC's gate pin through a small resistor (typically 47-100Ω). Pin 4 of the MOC3021 goes to MT1 of the BT138, and pin 6 goes to the gate.

AC connections: Connect mains Live to one side of your load. The other side of the load connects to the TRIAC's MT2 pin. The TRIAC's MT1 connects back to mains Neutral. The snubber capacitor (100nF, rated for 275V) connects across MT1 and MT2.

For ESP32 users, the logic is identical — just ensure you're using 3.3V logic levels. A level shifter or careful resistor selection ensures the MOC3021 triggers reliably.

Arduino Code for TRIAC Dimmer Control

Here's a clean, functional implementation using interrupts for precise timing:

const int ZC_PIN = 2;      // Zero-cross detection pin
const int TRIAC_PIN = 3;    // TRIAC gate control pin
const int AC_FREQ = 60;    // Set to 50 for 50Hz countries
const int HALF_CYCLE = 1000000 / (AC_FREQ * 2); // microseconds

volatile int brightness = 0;   // 0-100%
volatile bool triacFired = false;

void setup() {
  pinMode(ZC_PIN, INPUT_PULLUP);
  pinMode(TRIAC_PIN, OUTPUT);
  digitalWrite(TRIAC_PIN, LOW);

  // Trigger on zero-crossing (FALLING = end of half cycle)
  attachInterrupt(digitalPinToInterrupt(ZC_PIN), zeroCross, FALLING);
  Serial.begin(115200);
}

void loop() {
  // Adjust brightness via serial for testing
  if (Serial.available()) {
    int val = Serial.parseInt();
    if (val >= 0 && val <= 100) {
      brightness = val;
      Serial.print("Brightness set to: ");
      Serial.println(brightness);
    }
  }
}

ICACHE_RAM_ATTR void zeroCross() {
  triacFired = false;
  if (brightness == 0) {
    digitalWrite(TRIAC_PIN, LOW);
    return;
  }
  if (brightness == 100) {
    digitalWrite(TRIAC_PIN, HIGH);
    return;
  }

  // Calculate delay in microseconds
  // Full delay = half_cycle, no delay = 0
  int delayMicros = map(brightness, 0, 100, halfCycleDelay(brightness), 0);
  
  // Schedule TRIAC fire using micros()
  // We'll use a simple delay-based approach here
  delayMicroseconds(delayMicros);
  digitalWrite(TRIAC_PIN, HIGH);
  triacFired = true;
  delayMicroseconds(100); // Minimum gate pulse width
  digitalWrite(TRIAC_PIN, LOW);
}

int halfCycleDelay(int b) {
  // Maps brightness to delay in microseconds
  // brightness=100 → 0 delay (full wave)
  // brightness=1 → near full half-cycle delay
  return (HALF_CYCLE * (100 - b)) / 100;
}

This basic sketch gives you serial control over brightness. But the real power comes from connecting it to a web dashboard or Home Assistant automations.

Adding Web Control with ESP32

If you use an ESP32, you can add a web server directly on the dimmer — no Home Assistant required, though integration is easy if you have it. The ESP32's WiFi capability means you can control the dimmer from any browser or phone:

#include <WiFi.h>
#include <WebServer.h>

const char* ssid = "YOUR_WIFI";
const char* password = "YOUR_PASSWORD";

WebServer server(80);
int brightness = 50;

void handleRoot() {
  String html = "<html><body><h1>Smart Dimmer Control</h1>";
  html += "<p>Brightness: <span id='val'>" + String(brightness) + "</span>%</p>";
  html += "<input type='range' min='0' max='100' value='" + String(brightness) + "' ";
  html += "onchange='setBrightness(this.value)'>";
  html += "<script>function setBrightness(v){";
  html += "fetch('/set?b='+v).then(r=>document.getElementById('val').innerText=v);";
  html += "}</script></body></html>";
  server.send(200, "text/html", html);
}

void handleSet() {
  if (server.hasArg("b")) {
    brightness = server.arg("b").toInt();
    // Update TRIAC firing delay
  }
  server.send(200, "text/plain", "OK");
}

void setup() {
  WiFi.begin(ssid, password);
  server.on("/", handleRoot);
  server.on("/set", handleSet);
  server.begin();
}

void loop() {
  server.handleClient();
  // TRIAC control logic runs on interrupt
}

This gives you a slider-based web interface. Customize the HTML with your own styling for a sleek in-wall look.

Integrating with Home Assistant via MQTT

For a fully integrated smart home experience, connect your DIY dimmer to Home Assistant using MQTT. This lets you use Home Assistant's UI, voice assistants, and automations to control your dimmer alongside your commercial devices.

Set up your ESP32 to publish brightness state and subscribe to brightness commands via MQTT. In Home Assistant, add a light entity using the MQTT light platform:

mqtt:
  light:
    - name: "DIY TRIAC Dimmer"
      command_topic: "home/dimmer/set"
      state_topic: "home/dimmer/state"
      payload_on: "ON"
      payload_off: "OFF"
      brightness_command_topic: "home/dimmer/brightness"
      brightness_state_topic: "home/dimmer/brightness_state"
      qos: 1

This same MQTT approach works with Tasmota devices, giving you a consistent control interface across all your smart home gear.

Using Relay Modules as an Alternative

If the complexity of TRIAC circuits feels intimidating, a simpler approach for on/off and multi-level control uses relay modules with Arduino and ESP32. While relays can't do true dimming, you can create a stepped dimmer by wiring multiple bulbs through separate relays and switching combinations on and off. This is coarse and limited, but completely safe and easy to debug.

For precise brightness control, though, TRIAC is the only real option at the DIY level.

3D Printing a Custom Enclosure

Your dimmer needs a proper enclosure — never leave exposed mains voltage circuits in the open. You can design a custom enclosure in Tinkercad or Fusion 360 to fit:

  • The PCB or breadboard with all components
  • Terminal blocks for AC wiring
  • A rotary encoder with a 3D printed knob for manual control
  • An ESP32 with its antenna extending outside the enclosure

For PLA, print at 100% infill around high-heat components and consider PETG for better heat resistance. If your dimmer controls a heavy load (high-wattage halogen or LED), add ventilation holes and consider printing the enclosure in ASA or ABS for heat resistance. See our guide on designing weatherproof enclosures for tips on thermal management and cable glands.

Troubleshooting Common Issues

Flickering at low brightness: This is usually caused by inconsistent zero-cross detection. Check your optocoupler's wiring, ensure the resistors are correctly rated, and consider adding a small capacitor to smooth the zero-cross signal.

LED bulbs flickering or not dimming smoothly: Most LED bulbs are not designed for TRIAC dimming. Use dimmable LED bulbs explicitly labeled as "dimmable" or "TRIAC compatible." Regular LEDs may buzz, flicker, or refuse to dim at all. Smart LEDs controlled via PWM work much better for this use case.

TRIAC overheating: If the TRIAC gets hot to the touch, you may be exceeding its current rating. Add a heatsink or reduce the load. The BTA16 (16A) should handle most residential lighting but verify your actual load current.

ESP32 not triggering properly: ESP32 runs at 3.3V. The MOC3021 needs at least 15mA forward current — use a 220Ω resistor instead of 330Ω for 3.3V logic to ensure reliable triggering.

What Can You Control with This Dimmer?

Beyond standard incandescent and dimmable LED bulbs, a TRIAC dimmer can control:

  • Halogen lamps — traditional use, works flawlessly
  • Low-voltage halogen with magnetic transformers — works but watch for transformer hum
  • Universal LED drivers marked dimmable — test before committing
  • AC fans and motors — for motor speed control (use with appropriate current rating)
  • Soldering stations — many hakko-style stations use TRIAC dimmer control internally

Expanding the Project

Once your basic dimmer works, consider these upgrades:

  • Add a rotary encoder for tactile physical dimming control alongside the digital interface
  • Multi-channel dimming — use multiple TRIAC/MOC combos for RGBW control or multiple zones
  • Integrate with Alexa or Google Home using FauxmoESP or Google Assistant SDK on ESP32
  • Add an OLED display showing current brightness level and mode
  • Build it into a wall box using a standard Decora faceplate with a custom 3D printed insert

You can also combine this project with our guide to smart light switch wiring if you want to retrofit existing wall switches with your DIY dimmer.

Conclusion

Building a DIY smart light dimmer with Arduino and TRIAC is one of the most educational maker projects you can do. It touches on AC power electronics, microcontroller interrupts, real-time control systems, and smart home integration — all in one project. The satisfaction of controlling your lights with a custom-built device, through your own code, is hard to beat.

Start with low-voltage testing if you're new to this, use proper enclosures, and don't rush the safety aspects. Once it's working, you'll have a dimmer that's fully customizable to your exact needs — something no commercial product can offer.
