DIY Air Quality Monitor with ESP32 and Home Assistant: Complete Guide

📅 August 4, 2026 ⏱️ 14 min read ✍️ 3D Print Starter Team
💨

Air quality matters more than most people realize. The EPA estimates Americans spend 90% of their time indoors, where pollutant concentrations can be 2-5x higher than outside. Wildfire smoke, cooking fumes, off-gassing from furniture, and poor ventilation all degrade indoor air quality — and you might not even notice until symptoms appear.

Commercial air quality monitors cost $100-300, but you can build one for $30-50 with an ESP32 and the right sensors. In this guide, I'll show you how to build a complete DIY air quality monitor that tracks PM2.5, CO2, VOCs, temperature, and humidity — all feeding real-time data into Home Assistant.

If you're new to ESP32 and Home Assistant, start with our ESPHome Getting Started Guide to understand the basics before diving in.

What Sensors Do You Need for an Air Quality Monitor?

A comprehensive air quality monitor needs to measure several different parameters. Here's what each sensor tells you:

Pollutant Sensor What It Measures Risk Level
Particulate Matter PMS5003 PM1.0, PM2.5, PM10 particles High — wildfire smoke, dust
Carbon Dioxide SGP30 or MH-Z19 CO2 levels (0-5000 ppm) Medium — indicates ventilation
VOCs SGP30, BME680 Volatile organic compounds Medium — paints, cleaners, furniture
Temperature BME280, DHT22 Ambient temperature Low — affects comfort
Humidity BME280, DHT22 Relative humidity (20-80%) Medium — mold risk, comfort

My recommended starter combination: PMS5003 + SGP30 + BME280. This gives you particulate matter, CO2/VOCs, and temperature/humidity in one package. Total cost: around $25-35.

Shopping List: What to Buy

Required Components

  • ESP32 DevKit ($5-8) — Any ESP32 board works. See our Best ESP32 Development Boards guide for recommendations.
  • PMS5003 particulate sensor ($10-15) — Measures PM1.0, PM2.5, PM10. Get the version with the connector cable.
  • SGP30 or BME680 ($8-12) — SGP30 is easier to use, BME680 adds pressure sensing.
  • BME280 ($4-6) — I2C temperature, humidity, and pressure sensor for additional accuracy.
  • Jumper wires ($2-3) — Various male-to-female and male-to-male wires.
  • Micro USB cable — For power and programming.

Optional but Recommended

  • 3.3V to 5V logic level shifter — PMS5003 uses 5V logic; ESP32 uses 3.3V.
  • Perfboard and headers — For a more permanent build.
  • 3D printed enclosure — We'll cover design tips later.

Wiring Diagram: Connecting Everything

The wiring is straightforward once you understand which pins to use. Here's the complete connection table:

PMS5003 Connections

  • VCC → 5V (external supply, not ESP32's 5V pin if drawing >500mA)
  • GND → ESP32 GND
  • TX → ESP32 GPIO 16 (RX2)
  • RX → ESP32 GPIO 17 (TX2)

BME280 Connections (I2C)

  • VCC → ESP32 3.3V
  • GND → ESP32 GND
  • SDA → ESP32 GPIO 21
  • SCL → ESP32 GPIO 22

SGP30 Connections (I2C)

  • VCC → ESP32 3.3V
  • GND → ESP32 GND
  • SDA → ESP32 GPIO 21 (shared with BME280)
  • SCL → ESP32 GPIO 22 (shared with BME280)

Pro tip: Both BME280 and SGP30 use the same I2C pins, which is fine — I2C allows multiple devices on the same bus as long as they have different addresses. BME280 defaults to 0x76 or 0x77; SGP30 uses 0x58.

ESPHome Configuration: The Software

ESPHome makes sensor integration seamless. Here's the complete YAML configuration for your air quality monitor:

Base Configuration

esphome:
  name: air-quality-monitor
  platform: ESP32
  board: esp32dev

wifi:
  ssid: "YourWiFiSSID"
  password: "YourWiFiPassword"

api:
  password: "esphome_api_password"

ota:
  password: "esphome_ota_password"

logger:

I2C Setup

i2c:
  sda: GPIO21
  scl: GPIO22
  scan: true
  id: i2c_bus

PMS5003 Particulate Sensor

uart:
  id: uart_bus
  tx_pin: GPIO17
  rx_pin: GPIO16
  baud_rate: 9600

sensor:
  - platform: pmsx003
    type: PMS5003T
    uart_id: uart_bus
    pm_1_0:
      name: "Particulate Matter 1.0 µm"
      id: pm1_0
    pm_2_5:
      name: "Particulate Matter 2.5 µm"
      id: pm2_5
    pm_10_0:
      name: "Particulate Matter 10 µm"
      id: pm10_0
    temperature:
      name: "PMS5003 Temperature"
      id: pms_temp
    humidity:
      name: "PMS5003 Humidity"
      id: pms_humidity
    update_interval: 30s

BME280 Sensor

  - platform: bme280_i2c
    i2c_id: i2c_bus
    address: 0x76
    temperature:
      name: "Air Monitor Temperature"
      id: bme_temp
      oversampling: 4x
    humidity:
      name: "Air Monitor Humidity"
      id: bme_humidity
      oversampling: 4x
    pressure:
      name: "Air Monitor Pressure"
      id: bme_pressure
    update_interval: 30s

SGP30 CO2 and VOC Sensor

  - platform: sgp30
    i2c_id: i2c_bus
   eco2:

      id: sgp_eco2

Air Quality Index Calculation

Create a template sensor that calculates a unified Air Quality Index (AQI) based on EPA standards:

  - platform: template
    name: "Air Quality Index"
    id: aqi
    lambda: |-
      // Based on EPA PM2.5 AQI formula
      float pm25 = id(pm2_5).state;
      float aqi;
      
      if (pm25 <= 12.0) {
        aqi = (50 - 0) / (12.0 - 0) * (pm25 - 0) + 0;
      } else if (pm25 <= 35.4) {
        aqi = (100 - 51) / (35.4 - 12.1) * (pm25 - 12.1) + 51;
      } else if (pm25 <= 55.4) {
        aqi = (150 - 101) / (55.4 - 35.5) * (pm25 - 35.5) + 101;
      } else if (pm25 <= 150.4) {
        aqi = (200 - 151) / (150.4 - 55.5) * (pm25 - 55.5) + 151;
      } else if (pm25 <= 250.4) {
        aqi = (300 - 201) / (250.4 - 150.5) * (pm25 - 150.5) + 201;
      } else if (pm25 <= 350.4) {
        aqi = (400 - 301) / (350.4 - 250.5) * (pm25 - 250.5) + 301;
      } else {
        aqi = (500 - 401) / (500.4 - 350.5) * (pm25 - 350.5) + 401;
      }
      return round(aqi);
    unit_of_measurement: "AQI"
    icon: "mdi:air-filter"
    update_interval: 30s

Upload this config to your ESP32 and watch the sensors appear in Home Assistant automatically.

Creating Useful Home Assistant Automations

Raw data is only useful if it triggers action. Here are automations that make your air quality monitor actually work for you:

Automation 1: Alert When PM2.5 is Dangerous

alias: "Alert: Dangerous PM2.5 Levels"
trigger:
  - platform: numeric_state
    entity_id: sensor.pm2_5
    above: 55
condition:
  - condition: state
    entity_id: input_boolean.air_alerts_enabled
    state: "on"
action:
  - service: notify.persistent_notification
    data:
      title: "⚠️ Air Quality Alert"
      message: "PM2.5 is {{ states('sensor.pm2_5') }} µg/m³. Consider closing windows or running an air purifier."
  - service: notify.mobile_app_your_phone
    data:
      title: "Air Quality Warning"
      message: "PM2.5: {{ states('sensor.pm2_5') }} µg/m³"

Automation 2: CO2 Alert for Ventilation

alias: "Alert: High CO2 — Open Windows"
trigger:
  - platform: numeric_state
    entity_id: sensor.sgp30_eco2
    above: 1000
action:
  - service: notify.persistent_notification
    data:
      title: "💨 High CO2 Alert"
      message: "CO2 levels at {{ states('sensor.sgp30_eco2') }} ppm. Time to ventilate!"
  - service: switch.turn_on
    entity_id: switch.window_fan

Automation 3: Auto-Run Air Purifier

alias: "Auto: Air Purifier on Bad Air Quality"
trigger:
  - platform: numeric_state
    entity_id: sensor.air_quality_index
    above: 100
for:
  minutes: 15
action:
  - service: switch.turn_on
    target:
      entity_id: switch.air_purifier

3D Printing an Enclosure

A proper enclosure keeps dust off sensors while allowing airflow. Here's what to consider for your 3D printed case:

Design Considerations

  • Airflow holes: PMS5003 needs unobstructed airflow. Add honeycomb or slotted vents on at least two sides.
  • Sensor separation: Keep the BME680/SGP30 away from the ESP32's heat output to avoid false temperature readings.
  • Sensor positioning: PMS5003 intake and exhaust should be on opposite sides of the case.
  • Ventilation chamber: Create a small chamber specifically for gas sensors to get accurate ambient readings.

Recommended Print Settings

For a functional enclosure that fits all components:

  • Layer height: 0.2mm (balance between strength and print time)
  • Walls: 3-4 perimeters for structural integrity
  • Infill: 15-20% for most parts, 100% for mounting brackets
  • Material: PLA works fine for indoor use. PETG for better heat resistance near electronics.

Troubleshooting Common Issues

PMS5003 Shows All Zeros

  • Check UART wiring (TX→RX, RX→TX is correct)
  • Verify baud rate is 9600 in ESPHome config
  • Make sure sensor is getting 5V power — it won't work at 3.3V
  • Wait 30 seconds after power-on — PMS5003 needs time to initialize

SGP30 Reads Very Low eCO2

The SGP30 needs 12 hours of initial burn-in and then 1 hour per day to stabilize readings. Fresh sensors will read 400 ppm (outdoor baseline) until warmed up. After burn-in, it should track relative CO2 changes accurately.

BME280 Not Detected

  • Check I2C scan in ESPHome logs — it should list devices at 0x58, 0x76, 0x77
  • Verify SDA/SCL pins are correct (GPIO 21/22 on most ESP32)
  • Try different address (0x76 vs 0x77) — some BME280 modules use 0x77

Temperature Reading is Wrong

ESP32 chips get warm when under load. Keep the temperature sensor away from the processor and consider using the PMS5003's built-in temperature sensor for more accurate readings in the airflow.

Advanced: Adding More Sensors

Once your basic monitor works, consider upgrading with:

  • MH-Z19 CO2 sensor — More accurate than SGP30 for CO2, but larger and more expensive
  • ENS160 sensor — Newer AQI sensor with better VOC accuracy
  • CCS811 — Budget VOC/eCO2 option (less accurate than SGP30)
  • SDS011 — High-quality PM sensor for professional monitoring

Building Your Own Outdoor Sensor

The same principles apply to outdoor air quality monitoring, but you'll need weatherproofing. Key modifications:

  • Use IP65+ rated enclosures with ventilation membranes
  • Add a protective cover over PMS5003 intake to block rain
  • Consider solar power for remote locations
  • Use shielded cables to reduce noise

Conclusion: Breathe Better with Smart Monitoring

A DIY air quality monitor costs a fraction of commercial solutions while giving you complete control over data and integrations. Once your monitor is running, you'll gain visibility into how your home's air quality changes throughout the day — and the data often surprises people.

After building several air quality monitors around my home, I discovered that cooking without the range hood on immediately spikes PM2.5 to unhealthy levels, that CO2 climbs dangerously high during long work meetings, and that my daughter's room has chronically low humidity in winter.

The ESP32 + Home Assistant combination makes it easy to log historical data, create long-term trends, and build automations that respond automatically to air quality changes. Start with the basics — PMS5003 + BME280 — and expand from there.
