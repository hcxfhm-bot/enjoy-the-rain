How to Use G-Code to Control Your 3D Printer

📅 May 25, 2026 ⏱️ 9 min read ✍️ 3D Print Starter Team
💻

What Is G-Code?

G-code is the programming language that tells your 3D printer what to do. Every movement, temperature change, and extrusion command in a print file is written in G-code. While slicer software generates G-code automatically from your 3D models, understanding G-code commands lets you control your printer directly, troubleshoot issues, and customize behavior beyond what slicers offer.

Think of G-code as the bridge between your digital design and the physical print. When you click "print" in your slicer, it generates thousands of lines of G-code that your printer's firmware interprets and executes. Learning to read and write basic G-code gives you deeper control over your machine.

Most consumer 3D printers use Marlin firmware, which follows a standardized set of G-code commands. Other firmware like Klipper and Bambu's proprietary system use similar conventions with some extensions.

Sending G-Code to Your Printer

Before diving into commands, you need a way to send G-code to your printer. There are several options:

Via USB Connection

Connect your printer to a computer via USB and use a terminal program. Popular options include:

  • OctoPrint: Web interface with a terminal tab (highly recommended)
  • Pronterface: Desktop application for direct printer control
  • Cura: Has a printer console under the Monitor tab
  • Arduino IDE Serial Monitor: Basic but functional

If you're using OctoPrint, check out our OctoPrint setup guide to get started.

Via SD Card

Write G-code commands in a text file, save with a .gcode extension, and run it from your printer's SD card menu. This is useful for calibration scripts and maintenance routines.

Via Printer LCD

Some printers with advanced screens allow entering G-code commands directly through the menu interface.

Essential G-Code Commands

Here are the fundamental commands you'll use most often:

Movement Commands

G0 and G1 — Linear Move

The most basic commands. G0 is for rapid (non-printing) moves, G1 for printing moves. In practice, most firmware treats them identically.

G0 X50 Y50    ; Move to X=50, Y=50 rapidly
G1 Z5         ; Move Z to 5mm height
G1 X100 E10   ; Move X to 100, extrude 10mm

Parameters: X, Y, Z for coordinates; E for extruder position; F for feedrate (speed).

Home Commands

G28 — Auto Home

Moves all axes to their endstop positions, establishing the zero point.

G28           ; Home all axes
G28 X Y       ; Home X and Y only
G28 Z         ; Home Z only

Temperature Commands

M104/M109 — Set Hotend Temperature

M104 S200     ; Set hotend to 200°C (no wait)
M109 S200     ; Set hotend to 200°C and wait

M140/M190 — Set Bed Temperature

M140 S60      ; Set bed to 60°C (no wait)
M190 S60      ; Set bed to 60°C and wait

For temperature recommendations by filament, see our PLA temperature guide and PETG vs PLA comparison.

Position and Information

M114 — Report Position

Shows current position of all axes. Useful for debugging and manual calibration.

M105 — Report Temperature

Returns current temperatures of hotend and bed.

G92 — Set Position

Sets the current position to specified values without moving. Used at print start to define zero.

G92 E0        ; Reset extruder position to 0

Extruder Control

G92 E0 — Reset Extruder

Standard command at the start of prints to reset extruder position tracking.

M82/M83 — Extruder Mode

M82           ; Absolute extruder mode
M83           ; Relative extruder mode

Fan Control

M106/M107 — Part Cooling Fan

M106 S255     ; Fan on at 100% (0-255 range)
M106 S128     ; Fan on at 50%
M107          ; Fan off

Practical G-Code Scripts

Here are useful scripts you can save and run on your printer:

Heating Script

Pre-heat your printer before starting a print:

; Pre-heat for PLA
M140 S60        ; Start heating bed
M104 S200       ; Start heating hotend
M190 S60        ; Wait for bed
M109 S200       ; Wait for hotend
M300 S1000 P500 ; Beep when ready

Bed Leveling Test

Move nozzle to corners for manual bed leveling:

G28           ; Home all
G0 Z5         ; Raise Z
G0 X10 Y10    ; Front-left corner
G0 Z0.2       ; Lower to paper height
; Adjust knob here
G0 Z5         ; Raise
G0 X200 Y10   ; Front-right corner
G0 Z0.2
; Adjust knob here
; Repeat for back corners

For more on bed leveling, see our guide on how to level a 3D printer bed.

Nozzle Cleaning Script

Move to a convenient position for nozzle cleaning:

G28 X Y       ; Home X and Y
G0 X100 Y150  ; Move to accessible position
M104 S200     ; Heat to cleaning temp
M109 S200     ; Wait for temp
; Clean nozzle now
G28           ; Re-home when done

Extruder Calibration Script

For measuring and calibrating extruder steps:

G28           ; Home
M104 S200     ; Heat nozzle
M109 S200     ; Wait for temp
G92 E0        ; Reset extruder
G1 E100 F100  ; Extrude 100mm slowly
; Measure actual extrusion and calculate
; new steps-per-mm

Understanding Slicer-Generated G-Code

When you slice a model, the resulting G-code file starts with setup commands and then contains thousands of movement commands. Here's what a typical print file looks like:

; Generated by Cura
G28 ; Home
M140 S60 ; Heat bed
M104 S200 ; Heat nozzle
M190 S60 ; Wait for bed
M109 S200 ; Wait for nozzle
G92 E0 ; Reset extruder
G1 Z5 F3000 ; Move Z up
G1 X10 Y10 F6000 ; Move to start
; Layer 1
G1 X20 Y10 E2.5 F1500 ; Print first line
G1 X30 Y10 E5.0 ; Continue...
; ... thousands more lines ...

Understanding this structure helps you modify start/end G-code in your slicer for custom behaviors.

Start and End G-Code Customization

Most slicers let you customize the G-code that runs before and after each print. This is powerful for tailoring behavior to your specific needs.

Custom Start G-Code Example

G28 ; Home all axes
M140 S{material_bed_temperature_layer_0} ; Start bed heating
M104 S{material_print_temperature_layer_0} ; Start nozzle heating
M190 S{material_bed_temperature_layer_0} ; Wait for bed
M109 S{material_print_temperature_layer_0} ; Wait for nozzle
G92 E0 ; Reset extruder
G1 Z2 F3000 ; Raise Z
G1 X5 Y5 F6000 ; Move to corner
G1 Z0.3 F3000 ; Lower to first layer height
G1 X100 E20 F1000 ; Prime line
G92 E0 ; Reset again
G1 Z2 F3000 ; Raise Z

Custom End G-Code Example

G91 ; Relative mode
G1 E-2 F2700 ; Retract
G1 E-2 Z0.2 F2400 ; Retract and raise
G90 ; Absolute mode
G1 X0 Y200 F6000 ; Move bed forward
M106 S0 ; Fan off
M104 S0 ; Hotend off
M140 S0 ; Bed off
M84 ; Disable motors

Advanced G-Code Commands

For more advanced control, these commands are useful:

Acceleration and Jerk

M201 X500 Y500 ; Set max acceleration
M204 P500 R1000 T500 ; Set print acceleration
M205 X8 Y8 ; Set jerk

Steps Per MM (Calibration)

M92 X80 Y80 Z400 E93 ; Set steps per mm
M500 ; Save to EEPROM

Baby Stepping (Z Adjustment During Print)

M290 Z0.05 ; Raise Z by 0.05mm
M290 Z-0.05 ; Lower Z by 0.05mm

Safety Tips for G-Code

  • Always verify positions: Before moving, make sure the path is clear. A G0 command won't stop for collisions.
  • Don't exceed limits: Moving beyond your bed size can crash the gantry. Know your printer's dimensions.
  • Watch temperatures: Setting a temperature too high can damage your hotend. Stay within safe ranges for your hardware.
  • Save before experimenting: Use M500 to save settings to EEPROM before making permanent changes.
  • Test movements slow: When testing new scripts, use slow feedrates (F1000 or lower) until you're confident.

Conclusion

Understanding G-code opens up a new level of control over your 3D printer. From simple commands like homing and heating to complex calibration scripts, G-code lets you interact directly with your machine's firmware. Start by experimenting with basic movement and temperature commands, then progress to writing your own start/end scripts and calibration routines.
