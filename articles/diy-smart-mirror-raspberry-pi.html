How to Build a Smart Mirror with Raspberry Pi: MagicMirror² Complete Setup Guide

📅 June 13, 2026 ⏱️ 14 min read ✍️ 3D Print Starter Team
🪞

A smart mirror sounds like science fiction — a mirror that shows your calendar, weather, news headlines, and even controls your smart home, all while reflecting your room. Commercial smart mirrors cost $300–$800, but you can build one yourself for under $150 using a Raspberry Pi, a two-way mirror, and the free MagicMirror² platform.

This guide covers the full build from start to finish: choosing and sourcing a two-way mirror, setting up Raspberry Pi with MagicMirror², configuring the best modules, and 3D printing a custom frame to house everything. Whether you want a bathroom info display, a hallway dashboard, or a centerpiece for your maker workspace, this project delivers.

What Is a Smart Mirror?

A smart mirror is a display hidden behind a two-way (semi-transparent) mirror. The screen shows information widgets through the mirror glass when backlit, while the mirror surface still reflects your room and your reflection. The effect is a futuristic-looking display that doubles as a functional mirror.

MagicMirror² is the most popular open-source smart mirror platform. It runs on Node.js, uses a modular widget system, and has a massive community with hundreds of free modules for weather, calendars, Spotify controls, stock tickers, and more.

What You'll Need

Display & Mirror

  • Monitor (15–24 inch recommended) — An old laptop screen, a spare desktop monitor, or a purpose-bought IPS display. HDMI input is ideal. 1920×1080 is plenty for a mirror dashboard. Budget option: buy a used monitor for $20–$40.
  • Two-way acrylic mirror — The core of the build. You need a semi-transparent mirror, not a regular mirror. Acrylic is safer than glass and lighter. Available on Amazon for $30–$60 depending on size. Look for "two-way mirror acrylic" or "smart mirror glass."

Computing

  • Raspberry Pi 4 (4GB) or Pi 5 — MagicMirror² runs well on a Pi 4. The Pi 5 gives you snappier animations and more headroom for modules. A Pi 3B+ can work but page transitions feel sluggish. If you're new to Raspberry Pi, our Pi setup guide walks through flashing the OS and basic configuration.
  • MicroSD card (16GB+ Class 10) — A SanDisk Extreme or Samsung EVO for reliable read speeds.
  • Power supply — 5V 3A USB-C for Pi 4, 5V 5A for Pi 5. The official Raspberry Pi power supply is the safest bet.
  • Micro HDMI to HDMI cable — For connecting Pi to your monitor.

Frame & Housing

  • 3D printed frame or wooden frame — You can 3D print corner brackets to assemble a frame from aluminum extrusion, or build a simple wooden frame with a mitre saw. If you have a budget 3D printer, printing the frame components costs about $5–$10 in filament.
  • Black cardboard or foam board — To block light leaks around the monitor edges behind the mirror.
  • VHB tape or mounting brackets — To secure the monitor and mirror inside the frame.

Tools

  • Computer for initial Raspberry Pi setup (any OS works)
  • Screwdriver set for monitor disassembly
  • Soldering iron (optional) if you need to extend monitor cables — see our soldering station guide for recommendations
  • Wire cutters and electrical tape

Step 1: Prepare the Display

If you're using a laptop screen or a monitor with a thick bezel, you'll want to strip it down to bare essentials:

  1. Remove the plastic bezel — Most monitors have snap-fit bezels. Carefully pry them off with a plastic spudger or thin flathead screwdriver. Work around the edges, releasing the plastic clips.
  2. Remove the metal shield — Unscrew the metal frame behind the bezel. This exposes the LCD panel and its controller board.
  3. Keep the controller board accessible — You need the power input, HDMI input, and the ribbon cable connected to the LCD. Position the controller board so it fits alongside or behind the screen inside your frame.
  4. Test before proceeding — Connect everything, power it on, and verify the display works. Much easier to troubleshoot now than after it's inside the frame.

Tip: Some laptop screens use LVDS instead of HDMI. If that's your display, you'll need an HDMI-to-LVDS driver board (about $10 on AliExpress). These work fine for smart mirrors — just match the driver board to your panel's resolution and pin count.

Step 2: Install Raspberry Pi OS and MagicMirror²

Flash the OS

  1. Download Raspberry Pi Imager on your computer.
  2. Select Raspberry Pi OS (Legacy, 64-bit, Lite) — the Lite version is recommended because we don't need a desktop environment. MagicMirror² launches its own display server.
  3. Write to your microSD card and insert it into the Pi.
  4. Connect to ethernet or configure WiFi via raspi-config on first boot.

Install MagicMirror²

SSH into your Raspberry Pi (or connect a keyboard and monitor temporarily), then run:

# Update system packages
sudo apt update && sudo apt upgrade -y

# Install Node.js (v20 LTS recommended)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Install MagicMirror²
git clone https://github.com/MichMich/MagicMirror
cd MagicMirror
npm run install

# Copy the default config
cp config/config.js.sample config/config.js

# Launch it
DISPLAY=:0 npm start

If the installation fails with a Node.js version error, check your version with node -v. MagicMirror² requires Node.js 18+. If you have conflicts, try using nvm (Node Version Manager) to install and manage the correct version.

Auto-Start on Boot

You don't want to SSH in every time to start MagicMirror. Set up autostart:

# Install the Electron display server
sudo apt install -y chromium-browser unclutter

# Create an autostart script
sudo nano /etc/systemd/system/magicmirror.service

Paste this configuration:

[Unit]
Description=MagicMirror² Service
After=network.target

[Service]
User=pi
ExecStart=/usr/bin/node /home/pi/MagicMirror/serveronly
Restart=always
Environment=DISPLAY=:0

[Install]
WantedBy=multi-user.target

Then enable it:

sudo systemctl enable magicmirror
sudo systemctl start magicmirror

Your mirror now launches automatically every time the Pi boots.

Step 3: Configure Essential Modules

MagicMirror²'s default config comes with a few modules enabled. Edit ~/MagicMirror/config/config.js to customize. Here are the modules worth configuring:

Weather (built-in)

Get a free API key from OpenWeatherMap or WeatherAPI. Then configure:

{
  module: "weather",
  position: "top_right",
  config: {
    location: "Your City",
    locationID: "1234567",
    apiKey: "your_openweathermap_key",
    units: "imperial"
  }
}

Calendar (built-in)

Connect your Google Calendar for daily agenda:

{
  module: "calendar",
  position: "top_left",
  config: {
    calendars: [
      {
        symbol: "📅",
        url: "https://calendar.google.com/calendar/ical/YOUR_EMAIL/public/basic.ics"
      }
    ],
    maximumEntries: 5,
    timeFormat: "relative"
  }
}

To get your Google Calendar URL: open Google Calendar → Settings → your calendar → "Secret address in iCal format." Copy the URL.

News Feed (built-in)

{
  module: "newsfeed",
  position: "bottom_bar",
  config: {
    feeds: [
      {
        title: "TechCrunch",
        url: "https://techcrunch.com/feed/"
      },
      {
        title: "Hacker News",
        url: "https://news.ycombinator.com/rss"
      }
    ],
    showSourceTitle: true,
    showPublishDate: true,
    numEntries: 8
  }
}

Third-Party Modules Worth Installing

These modules aren't included by default but are easy to add:

  • MMM-Remote-Control — Control your mirror from a browser. Install: cd ~/MagicMirror/modules && git clone https://github.com/Jopyth/MMM-Remote-Control. Access at http://pi-ip:8080. Great for debugging and changing settings without SSH.
  • MMM-Spotify — Display and control your Spotify playback. Requires a Spotify Premium account and client credentials from the Spotify Developer Dashboard.
  • MMM-HomeAssistant — Connect to your Home Assistant server to display sensor data and control devices. See our Home Assistant integration guide for setup details.
  • MMM-CalendarExt3 — A more visually appealing calendar with week views, event coloring, and location-based icons.
  • MMM-GooglePhotos — Display a slideshow of your Google Photos library. Perfect for a hallway mirror.

To install any third-party module, the process is the same:

cd ~/MagicMirror/modules
git clone https://github.com/AUTHOR/MODULE-NAME.git
cd MODULE-NAME
npm install

Then add the module configuration block to config.js. Most module GitHub repos include a README with the exact configuration to copy.

Step 4: Build the Frame

The frame is what separates a polished smart mirror from a science fair project. You have two main approaches:

Option A: 3D Printed Frame

Search Thingiverse or Printables for "smart mirror frame" — there are dozens of designs. A typical 3D printed frame consists of:

  • Four corner brackets — These clip onto aluminum extrusion (T-slot or V-slot profile) and hold the monitor and mirror in place.
  • Side clips — Optional clips that run along the edges to prevent the mirror from shifting.
  • Cable management channel — A printed channel that routes the Pi's power cable neatly.

Recommended print settings:

  • Material: PLA is fine for indoor use; use PETG if your bathroom mirror will see humidity
  • Infill: 30–50% (these parts need some strength)
  • Layer height: 0.2mm — no need for super fine resolution on functional parts
  • For PETG settings, check our PETG vs PLA guide

Assembly: cut four pieces of 20mm aluminum extrusion to your mirror dimensions. Slide the printed brackets on, insert your monitor and mirror, and tighten the brackets. The whole assembly is surprisingly rigid.

Option B: Wooden Frame

Build a simple shadow box from 1×3 or 1×4 pine boards:

  1. Cut four boards to size with 45° mitres for clean corners.
  2. Glue and screw the frame together.
  3. Paint or stain it black for the best look behind a mirror.
  4. Mount the monitor inside with foam tape or small L-brackets.
  5. Place the two-way mirror on top of the monitor, and use small foam pads in the corners to hold it in place without adhesive.

This approach is simpler and doesn't require a 3D printer, but the 3D printed frame gives you a more modern, precise look.

Handling the Mirror

Two-way acrylic mirrors are surprisingly easy to work with but have a few quirks:

  • Peel the protective film only when you're ready for final assembly — it scratches easily.
  • Clean with microfiber only — paper towels and ammonia-based cleaners will damage the semi-reflective coating.
  • The reflective side faces outward (toward the room). The translucent side faces inward toward the monitor.
  • Block all side light — If ambient light leaks into the gap between the monitor and mirror, it washes out the display. Use black foam board or electrical tape to seal all edges.

Step 5: Monitor Orientation

Most smart mirrors work best in portrait orientation (tall and narrow). If your monitor's native orientation is landscape, rotate it 90° and tell the Raspberry Pi:

# Edit the boot config
sudo nano /boot/firmware/config.txt

# Add this line (rotate 90° clockwise; use 1 for 270° if your screen is upside down)
display_rotate=1

Reboot and your display should be in portrait mode. If it's upside down, change display_rotate=1 to display_rotate=3.

Step 6: Fine-Tune the Display

Brightness Control

You'll want the screen bright enough to read through the mirror but not so bright that the mirror becomes obviously a screen. Some tips:

  • Set monitor brightness to 70–80% as a starting point. Adjust based on room lighting.
  • Use the MMM-Remote-Control module to adjust brightness from your phone instead of physically reaching the monitor.
  • Consider adding a light sensor to auto-adjust brightness based on ambient light — the MMM-LightSensor module handles this.

Hide the Cursor

MagicMirror² doesn't show a cursor by default when running in server mode, but if you see one:

sudo apt install unclutter
# Add to autostart
unclutter -display :0 -noevents &

Touch Support (Optional)

If your monitor supports touch input (many IPS panels do), you can add touch functionality. Install xdotool and enable touch modules for interactive widgets. This turns your smart mirror into a smart display — great for bathroom counters or kitchen walls.

Step 7: Integrate with Home Assistant

One of the best uses for a smart mirror is as a Home Assistant dashboard. With the MMM-HomeAssistant module, your mirror can display:

  • Temperature and humidity from your DIY weather station
  • Door lock status from your smart door lock
  • Energy consumption from smart plugs and sensors
  • Quick toggles for lights, fans, and appliances
  • Security camera feeds if you have ESP32 cameras running ESPHome

Setup: install the module, configure your Home Assistant server URL and long-lived access token (generated in HA → Profile → Security → Long-lived access tokens), then add the entity cards you want to display. Each card can show a sensor reading, a toggle switch, or a graph.

Step 8: Power Management

Smart mirrors run 24/7 in most setups. A few considerations:

  • Power consumption — A Raspberry Pi 4 + 24" monitor uses about 20–30W total, roughly $2–4/month in electricity. Not bad for a 24/7 smart display.
  • UPS (optional) — A small battery backup keeps the mirror running through brief power outages. A 12V battery with a simple charging circuit can provide 30–60 minutes of backup.
  • Scheduled sleep — Use cron on the Pi to turn off the monitor via HDMI-CEC during night hours: echo "on 0" | cec-client -s / echo "standby 0" | cec-client -s.

Common Problems and Fixes

Screen Is Too Visible Through the Mirror

Reduce monitor brightness. If it's still too visible, add a neutral density filter or switch to a mirror with a lower transmission rate (40% vs 70%). Some builders use privacy screen film applied to the monitor to reduce visibility further.

MagicMirror² Won't Start

Check Node.js version (node -v — need 18+). Check the log with pm2 logs MagicMirror if you use PM2 for process management. Most failures come from a module that failed to install — try removing modules one by one until it starts.

Monitor Shows "No Signal"

Verify the HDMI cable is seated firmly. On the Pi 4, the micro HDMI port can be finicky. Try the other HDMI port. If you're using an HDMI-to-LVDS board, check the panel resolution matches the board's configuration.

WiFi Drops Frequently

A wired ethernet connection is strongly recommended. If you must use WiFi, add a high-gain USB adapter or position the Pi closer to your router. Smart mirrors are typically wall-mounted in locations with worse WiFi reception.

What's Next?

Once your basic mirror is running, here are some upgrades to explore:

  • Voice control — Add a USB microphone and use Mycroft or Snowboy for wake-word detection to control modules hands-free.
  • Face recognition — The MMM-Facial-Recognition module identifies who's looking at the mirror and shows personalized information (their calendar, their commute time, etc.).
  • Gesture control — A small ESP32 camera module can detect hand waves and swipes to scroll through news or dismiss notifications.
  • Multi-mirror network — Run the same MagicMirror² instance across multiple mirrors in different rooms, each showing location-relevant content.

Conclusion

Building a DIY smart mirror is one of the most rewarding maker projects you can tackle. It combines electronics, software, and fabrication into a finished product that you actually use every day. With a Raspberry Pi, a two-way mirror, and some basic tools, you can create something that would cost hundreds of dollars commercially — and have full control over every widget and module on your mirror.

The total investment is modest (around $100–$200 depending on how much you already have), and the result is a genuinely useful smart home device that impresses everyone who sees it. Start with the basic modules, get the hardware assembled, and then iterate — add Home Assistant integration, face recognition, and voice controls as you go. That's the beauty of open-source: there's always another module to try.
