How to Print Multi-Color on a Single-Extruder 3D Printer

📅 May 16, 2026 ⏱️ 8 min read ✍️ 3D Print Starter Team
⚡

Multi-color 3D printing sounds like you need a $600 Bambu AMS or a Prusa MMU3. But you don't. You can print in 2, 3, or even 5+ colors on a basic single-extruder printer for the cost of extra filament spools and a few minutes of hands-on time per print.

In this guide, I'll show you the 3 methods that actually work in 2026 — from the dead-simple "pause and swap" technique to using your slicer's built-in multi-material tools. No hardware upgrades required for Methods 1 and 2.

Method 1: Manual Filament Change (Pause at Layer)

This is the most accessible method. You literally pause the printer when it reaches a specific layer height, swap the filament, and resume. It's how I printed my first multi-color name tag back in 2018, and it still works perfectly on every modern printer.

Step 1: Prepare Your Model

Multi-color prints work best when colors are separated by height, not by X/Y position. Think: a base in one color, text on top in another color. If you need two colors side-by-side at the same layer height, skip to Method 3 (painting in the slicer).

Good candidates for manual filament change:

  • Name tags (base color + text color)
  • Coasters (one color background, another for the design)
  • Signs and plaques
  • Keychains with a two-tone design

Step 2: Set the Pause in Your Slicer

In Cura:

  1. Slice your model normally.
  2. Click the Preview tab.
  3. Slide the layer slider to find the exact layer where you want the color change (e.g., layer 50).
  4. Click the ... button (Extensions) → Post Processing → Modify G-Code.
  5. Add a script → select "Pause at height".
  6. Enter the layer number, and set "Pause at" to "Layer".
  7. Optionally set a park position (X: 0, Y: 0 to move the nozzle out of the way).

In OrcaSlicer / Bambu Studio:

  1. Slice the model.
  2. Right-click the model in the preview → Add Pause / Color Change.
  3. Select the layer, confirm. A pause icon appears on that layer.
  4. Repeat for each color change in your print.

Step 3: Run the Print and Swap Filament

When the printer pauses: (1) Retract the current filament. (2) Load the new color. (3) Purge 20-30mm of filament until the new color comes through cleanly. (4) Wipe the nozzle. (5) Resume the print.

Pro tip: Set your nozzle temperature 5-10°C higher during the filament swap (e.g., 215°C instead of 205°C). This helps push out the old color completely. Just remember to set it back after the swap.

Method 2: M600 Command (G-Code Injection)

If your printer supports the M600 G-code command (most Marlin and Klipper printers do), this is cleaner than Method 1 because the printer automatically moves the nozzle aside, retracts the filament, and waits for you to load the new one.

How to Inject M600

In Cura, use the "ChangeAtZ" post-processing script and select "M600" as the pause method. In PrusaSlicer, use the "Color Change" placeholder in the custom G-code section.

The M600 command triggers a filament change routine built into your printer's firmware. You don't need to manually retract or unload — the printer does it. Load the new filament when prompted, press the button, and it purges automatically.

Check compatibility: Some entry-level printers (especially older Ender 3 variants with 8-bit boards) don't support M600. Test with a small 10-layer calibration cube first.

Method 3: Paint-to-Print (OrcaSlicer / Bambu Studio)

This is the most powerful method. Instead of separating colors by layer height, you paint different areas of the model with different colors in the slicer. The slicer then generates G-code that pauses and changes filament at each color boundary.

How to Do It in OrcaSlicer

  1. Import your model into OrcaSlicer.
  2. Select the model → click Paint (brush icon in the left toolbar).
  3. Choose a color, paint the areas you want in that color.
  4. Repeat for each color (up to 4-6 colors in the free version).
  5. Click Slice. OrcaSlicer will insert automatic color changes (M600 or pause commands) at each boundary.

This method produces the most impressive results — think a 3D-printed Pikachu with yellow body, red cheeks, and black eyes, all printed in one job on a single nozzle. The downside? You'll be standing at your printer doing 4-6 filament swaps per print.

How Many Colors Can You Realistically Do?

With a single extruder, I've done up to 6 color changes in one print. But more than 3-4 becomes impractical because: (1) each swap adds 2-5 minutes of hands-on time, and (2) there's a small visual seam at each color transition where the filament didn't fully purge.

My rule of thumb: 2-3 colors for practical prints. 4+ colors only for display pieces where you're willing to babysit the printer.

Minimizing Color-Bleed at Transition Layers

The biggest visual problem with single-extruder multi-color is "color bleed" — a thin line of the old color visible in the new color's first few layers. Here's how to minimize it:

  • Purge more filament — In your pause script, increase the purge length to 50-80mm instead of the default 20mm.
  • Wipe the nozzle — Keep a brass brush or paper towel handy. Wipe the nozzle tip after each swap.
  • Use a prime tower — In Cura/OrcaSlicer, enable "Prime Tower" in the multi-material settings. This wastes some filament but gives clean color transitions.
  • Match colors strategically — Going from black → white is the hardest transition. Going from red → orange → yellow is much easier.

When to Upgrade to a Multi-Material System

If you're doing multi-color prints weekly and want to walk away from the printer, it's time to upgrade. Options in 2026:

  • Bambu Lab AMS ($249) — Works with Bambu X1/P1/A1 series. 4 colors, automatic. The gold standard.
  • Creality CFS ($180) — Newer system for Creality K1 and Ender 3 V3 series. 4 colors.
  • ERCF v2 (DIY) ($80-120) — Open-source filament changer for Voron/Prusa printers. Steep learning curve but very capable.

But if you're just getting started with multi-color, don't buy anything. Master Methods 1-3 first. You'll learn what color combinations look good and whether you actually enjoy the workflow before spending $200+ on a multi-material system.

Best First Multi-Color Project

Print a two-tone keychain or name tag. They take 30-45 minutes, use only 2 colors (one base, one text), and the manual pause method is all you need. Once you nail that, move up to a 3-color coaster or sign.
