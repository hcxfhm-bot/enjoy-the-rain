How to Build a DIY Home Security System with ESP32 and Home Assistant

📅 June 18, 2026 ⏱️ 12 min read ✍️ 3D Print Starter Team
🔒

Commercial home security systems can cost $300 to $600 upfront, plus $15–$45 per month for monitoring. But here's the thing: you can build your own DIY home security system that's just as effective for a fraction of the cost—using an ESP32 microcontroller and Home Assistant.

In this guide, you'll learn how to build a complete home security system from scratch. We'll cover motion detection, door/window sensors, a siren, and automated alerts—all connected to Home Assistant so you can monitor and control everything from your phone. No monthly fees, no contracts, full ownership.

Why Build Your Own Security System?

Before we dive in, let's look at why a DIY approach makes sense:

  • Cost savings — A full system with multiple sensors costs under $100 in parts
  • No subscriptions — Self-hosted means no monthly monitoring fees
  • Full customization — Add any sensor, change automations, expand whenever you want
  • Privacy control — Your data stays on your local network, not in someone's cloud
  • Maker satisfaction — You built it yourself, and you understand every component

Plus, if you're already running Home Assistant on a Raspberry Pi, adding security features is a natural next step that leverages your existing setup.

What You'll Need: Parts List

Here's everything you need to build a solid DIY security system. You can start with one ESP32 and expand from there.

Core Components

  • ESP32 development boards ($5–$8 each) — 2–3 boards for different zones
  • HC-SR501 PIR motion sensors ($2–$3 each) — Detect movement in rooms and hallways
  • Magnetic door/window sensors ($1–$2 each) — Reed switches for entry points
  • Active buzzer or piezo siren ($2–$3) — Audible alarm trigger
  • DHT22 temperature/humidity sensor ($3–$5) — Optional: environmental monitoring
  • Jumper wires, breadboards, and USB cables ($5–$10 total)
  • 3D printed enclosures (free if you have a 3D printer) — Protect your electronics

Estimated Total Cost

A basic 3-sensor system (1 motion, 2 door sensors, 1 siren) costs roughly $25–$40 in components. Compare that to a $300 commercial system—it's a no-brainer for makers.

System Architecture Overview

Here's how all the pieces work together:

  • ESP32 boards connect to sensors via GPIO pins and communicate over WiFi to Home Assistant
  • ESPHome (an ESPHome add-on) runs on each ESP32, translating sensor data into Home Assistant entities
  • Home Assistant acts as the central hub — stores sensor states, runs automations, and sends notifications
  • Automations trigger actions when sensors change state: send phone alerts, activate sirens, turn on lights

The beauty of this architecture is modularity. Each sensor node is independent—if one ESP32 fails, the others keep working. You can also 3D print custom cases for each node to mount them neatly around your home.

Step 1: Set Up Home Assistant (If You Haven't Already)

If you don't have Home Assistant running yet, check our complete Raspberry Pi setup guide. You'll need:

  • A Raspberry Pi 4 (2GB or more) or any computer running 24/7
  • Home Assistant OS installed (easiest method)
  • ESPHome add-on installed from the Home Assistant Supervisor

Once Home Assistant is running, go to Settings → Add-ons → Add-on Store and install the ESPHome add-on. Start it, and make sure "Show in sidebar" is enabled. This is the bridge between your ESP32 boards and Home Assistant.

Step 2: Wire a Motion Sensor Node

Let's start with a motion sensor—one of the most useful security devices. The HC-SR501 PIR sensor is incredibly simple to wire.

Wiring Diagram

  • HC-SR501 VCC → ESP32 5V (or VIN pin)
  • HC-SR501 GND → ESP32 GND
  • HC-SR501 OUT → ESP32 GPIO 27 (or any digital input pin)

Adjusting the PIR Sensor

The HC-SR501 has two potentiometers on the back:

  • Time delay — Controls how long the output stays HIGH after detecting motion (turn clockwise for longer, up to ~5 minutes)
  • Sensitivity — Controls detection range (turn clockwise for ~7m range, counterclockwise for ~3m)

For security use, set sensitivity to maximum range and the time delay to around 5–10 seconds. You want quick resets so the sensor can detect new motion events rapidly.

Step 3: Wire Door and Window Sensors

Magnetic reed switches are the simplest sensors you'll ever use. They have two parts: a magnet and a switch. When the magnet moves away from the switch, the circuit opens.

Wiring

  • Connect one wire to ESP32 GPIO 14 (or another digital pin)
  • Connect the other wire to GND
  • Enable the internal pull-up resistor in your ESPHome config (the pin reads HIGH when the door is closed, LOW when open)

Mount the magnet part on the door or window frame, and the switch part on the moving door or window itself. When the door opens, the magnet separates from the switch, and Home Assistant detects the change instantly.

Step 4: Add a Siren Output

An active buzzer connects directly to a GPIO pin. When you set the pin HIGH, it makes noise.

  • Buzzer + → ESP32 GPIO 26
  • Buzzer − → ESP32 GND

You can wire the buzzer to the same ESP32 as your motion sensor, or put it on a dedicated board near the front door for maximum attention when triggered.

Step 5: Flash ESPHome Firmware

Now comes the software side. Create a new device in the ESPHome dashboard (accessible from Home Assistant's sidebar).

Example ESPHome YAML Configuration

Here's a complete configuration for a node with motion sensor, door sensor, and siren:

substitutions:
  device_name: security-node-1

esphome:
  name: ${device_name}

esp32:
  board: nodemcu-32s

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

# Enable fallback hotspot
ap:
  ssid: "${device_name}"
  password: "12345678"

logger:
api:
ota:

# Binary sensor: PIR motion
binary_sensor:
  - platform: gpio
    pin:
      number: GPIO27
      mode: INPUT_PULLUP
    name: "${device_name} Motion"
    device_class: motion

  - platform: gpio
    pin:
      number: GPIO14
      mode:
        input: true
        pullup: true
    name: "${device_name} Front Door"
    device_class: door

# Output: Siren
output:
  - platform: gpio
    pin: GPIO26
    id: siren_output

switch:
  - platform: output
    name: "${device_name} Siren"
    output: siren_output
    icon: mdi:alarm-bell

Replace wifi_ssid and wifi_password with your actual WiFi credentials (stored as secrets in ESPHome for security). Click Install to flash this firmware to your ESP32.

Step 6: Create Home Assistant Automations

With your sensors appearing in Home Assistant, it's time to set up the intelligence. Go to Settings → Automations and create these automations:

Automation 1: Instant Phone Alert on Motion

  • Trigger: Binary sensor "security-node-1 Motion" changes to ON
  • Condition: Only when "Security Mode" input_boolean is ON
  • Action: Send a notification to your phone with the zone name and timestamp

Automation 2: Siren on Unauthorized Entry

  • Trigger: Door sensor changes to OPEN
  • Condition: Security Mode is ON, and nobody is home
  • Action: Turn ON siren switch → Wait 60 seconds → Turn OFF siren → Send notification

Automation 3: Arm/Disarm with a Toggle

  • Create an input_boolean called "Security Mode" in your configuration
  • Add a toggle card to your Home Assistant dashboard
  • Use this as the master switch for all security automations

For more automation ideas, check out our Home Assistant automations beginner's guide.

Step 7: Add More Zones

One ESP32 can handle multiple sensors, but for larger homes, you'll want multiple nodes:

  • Zone 1 (Living room): Motion sensor + door sensor on front door
  • Zone 2 (Back door/Garage): Door sensors + motion sensor
  • Zone 3 (Bedroom hallway): Motion sensor for nighttime alerts
  • Zone 4 (Windows): Magnetic sensors on ground-floor windows

Each node gets its own ESPHome configuration. The process is identical—just change the device name, WiFi credentials (same network), and GPIO pin assignments. All nodes appear automatically in Home Assistant.

Step 8: 3D Print Custom Enclosures

If you have a 3D printer, you can print custom sensor housings that match your home's aesthetics. This is where the 3D printing and smart home worlds overlap beautifully:

  • PIR sensor dome — Print a white hemisphere cover that diffuses the sensor for wider detection
  • Door sensor mounts — Custom-fit mounts for uneven door frames
  • ESP32 waterproof boxes — For outdoor sensor nodes (use PETG for weather resistance — see our PETG vs PLA comparison)
  • Siren housing — A directional horn that amplifies the buzzer output

You'll find plenty of open-source designs on sites like Printables and Thingiverse. Search for "ESP32 case," "PIR sensor mount," or "smart home sensor housing."

Taking It Further: Advanced Features

Once your basic system is running, here are some powerful upgrades:

  • ESP32-CAM integration — Add a camera module to capture photos when motion is detected and send them to your phone via Telegram
  • MQTT for faster response — Configure MQTT for sub-second sensor updates instead of polling
  • Deep sleep mode — Battery-powered window sensors that sleep between checks, lasting months on a charge
  • Glass break sensors — Sound-based sensors that detect breaking glass
  • Keypad arming — Add a numeric keypad at the front door to arm/disarm without your phone
  • Tasmota or ESPHome for existing smart plugs — Integrate commercial smart devices into your security automations

Troubleshooting Common Issues

Here are solutions to the most common problems you might encounter:

  • Sensor triggers randomly — The PIR sensor may be detecting pets or air currents. Adjust the sensitivity dial or add a lens cover to narrow the detection cone
  • ESP32 keeps disconnecting — WiFi range issues. Move the board closer to your router, or add a WiFi extender. You can also try lowering the WiFi power save mode in ESPHome
  • Door sensor always shows OPEN — Check the wiring and ensure the internal pull-up resistor is enabled. The magnet may also be too far from the reed switch (keep within 1cm)
  • Siren doesn't stop — Add a timeout in your automation (always include a "turn off after X seconds" action)
  • Notifications delayed — Check your Home Assistant notification integration (mobile app companion, Telegram bot, or email)

Cost Comparison: DIY vs. Commercial

Here's a realistic cost breakdown for a typical 3-bedroom home:

  • DIY (this guide): $50–$80 for hardware + $0/month = $50–$80 total
  • DIY + Raspberry Pi: $50–$80 + $55 Pi 4 = $105–$135 total
  • Ring Alarm (5-piece kit): $200 + $20/month monitoring = $440 over 1 year
  • SimpliSafe (Essential): $300 + $25/month = $600 over 1 year

The DIY system pays for itself in 2–3 months compared to commercial options. And you get the satisfaction of having built it yourself.

Conclusion

Building a DIY home security system with ESP32 and Home Assistant is one of the most practical and rewarding maker projects you can tackle. It combines electronics, programming, 3D printing, and home automation into one cohesive system that actually protects your home.

Start with a single motion sensor node. Once you see it working in Home Assistant, you'll want to add more sensors, more automations, and more smart features. Before you know it, your home will be smarter and more secure—and you built every piece of it.

The best security system is the one you understand and control. With ESP32 and Home Assistant, that's exactly what you get.
