3D Print Layer Height Guide: How It Affects Quality & Speed

📅 May 23, 2026 ⏱️ 6 min read ✍️ 3D Print Starter Team
🎯

Layer height is the distance between each horizontal layer of your print. It's the single most impactful setting for balancing quality against speed. Lower layers = more detail but slower. Higher layers = faster but more visible layer lines.

But layer height does more than affect looks. It changes print strength, surface quality, and even how well overhangs print. This guide breaks down exactly what each layer height range does, when to use it, and what the trade-offs are.

How Layer Height Works

Your printer deposits filament in thin horizontal bands. Each band is one layer. At 0.20mm layer height, a 20mm tall object has 100 layers. At 0.12mm, the same object has 167 layers — 67% more layers, 67% more time, but noticeably smoother surfaces.

Key rule: Layer height must be between 25% and 75% of your nozzle diameter. For a standard 0.4mm nozzle:

  • Minimum practical: 0.08-0.10mm
  • Maximum practical: 0.28-0.32mm
  • Sweet spot: 0.16-0.20mm

Going below 0.08mm with a 0.4mm nozzle doesn't improve quality — the filament can't be squished thin enough to form proper layers. For ultra-fine detail, you need a smaller nozzle (0.2mm or 0.25mm).

Layer Height Ranges Explained

0.08-0.12mm — Ultra Fine

Near-invisible layer lines on most prints. Used for miniatures, jewelry, and display pieces where surface quality is everything.

  • Quality: Excellent. Smooth surfaces, sharp details.
  • Speed: Very slow. A print that takes 2 hours at 0.20mm takes 3.5-4 hours at 0.10mm.
  • Strength: Slightly weaker. More layers = more layer boundaries = more potential failure points.

0.16-0.20mm — Standard (Most Popular)

The default for a reason. Good quality at reasonable speed. Layer lines are visible up close but not distracting.

  • Quality: Good. Suitable for most prints.
  • Speed: Balanced. A typical benchy prints in 1.5-2 hours.
  • Strength: Good. The standard baseline.

0.24-0.28mm — Draft / Fast

Obvious layer lines, but fast. Use for prototypes, test fits, and functional parts where looks don't matter.

  • Quality: Rough. Layer lines clearly visible.
  • Speed: Fast. That same benchy prints in under an hour.
  • Strength: Slightly stronger per-layer, but interlayer bonding is the same.

Layer Height vs. Strength: The Surprise

Many people assume thinner layers = stronger prints. The reality is more nuanced:

  • Tensile strength (pulling layers apart): Thinner layers are actually slightly stronger because each layer is pressed harder into the one below (more squish = better bonding).
  • Impact resistance: Thicker layers resist impact slightly better — more material per layer absorbs energy.
  • Z-axis strength: All FDM prints are weakest between layers, regardless of height. If you need Z-strength, orient the part so stress isn't pulling layers apart.

Bottom line: Layer height doesn't dramatically change strength. Don't choose 0.28mm "for strength" — it won't help noticeably. Choose based on quality and speed needs instead.

PETG and TPU don't benefit much from ultra-fine layers. Their natural viscosity means 0.12mm doesn't look dramatically better than 0.16mm. Save the fine settings for PLA. For more per-filament settings, see our complete settings guide.

Variable Layer Height (Adaptive Slicing)

Most modern slicers support variable layer height — using fine layers on detailed areas and coarse layers on flat or hidden areas. This is a massive time-saver.

Example: A figurine with detailed facial features and a smooth robe. Use 0.12mm on the face, 0.20mm on the robe, and 0.28mm on the base. You get the detail where it matters and the speed where it doesn't.

  • Cura: "Adaptive Layers" experimental setting
  • PrusaSlicer: "Variable layer height" with the slider tool
  • Bambu Studio: Built-in adaptive layer height

Layer Height and Overhangs

Lower layer heights improve overhang printing because each layer extends less far outward from the one below. At 0.12mm, you can print 50° overhangs cleanly. At 0.28mm, even 45° overhangs start to sag.

If your prints have droopy overhangs, try reducing layer height before adding more supports. It's often the simpler fix. Our overhang printing guide goes deeper into this.

5 Common Layer Height Mistakes

  • Always using 0.12mm "for quality": You're wasting 50% more time on parts that don't need it. Use fine layers only for visible, detailed surfaces.
  • Going below nozzle limits: 0.06mm with a 0.4mm nozzle doesn't work well. The extruder can't push filament precisely enough.
  • Ignoring first layer height: Your first layer should be 0.20-0.30mm regardless of the rest of the print. A thicker first layer squishes into the build plate for better adhesion. If your first layer fails, our first layer troubleshooting guide can help.
  • Not matching speed to layer height: Fine layers need slower speeds (30-40mm/s). Fast speeds + fine layers = vibrations and ringing.
  • Using thick layers for small features: If your model has 0.4mm detail, 0.28mm layers will miss it entirely.

Conclusion

Start with 0.20mm as your default. It's the sweet spot for quality and speed with every filament. Move to 0.12mm for display pieces and miniatures. Use 0.28mm for quick prototypes and functional parts. And when you want the best of both worlds, try variable layer height — it's the single most underrated feature in modern slicers.
