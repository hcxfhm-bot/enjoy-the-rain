ESP32 Web Server Tutorial: Control LEDs and Sensors from Your Browser

📅 August 18, 2026 ⏱️ 12 min read ✍️ 3D Print Starter Team
🌐

One of the most powerful features of the ESP32 is its built-in Wi-Fi capability. Combine that with a little bit of HTML and JavaScript, and you can build a fully functional web server that runs directly on the chip — no Raspberry Pi required, no cloud subscription, no monthly fees. In this ESP32 web server tutorial, you'll learn how to control LEDs, read sensor data, and create a responsive web dashboard that works on any device in your house.

Why Build an ESP32 Web Server?

Before we dive in, let's address the obvious question: why not just use a pre-built solution like Tasmota or ESPHome? Both are excellent platforms that already include web server functionality out of the box.

The answer is customization. When you build your own web server from scratch, you have complete control over every pixel, every API endpoint, and every interaction. Want a button that triggers a specific sequence of events? Want to display sensor data in a custom visualization? Want to integrate with a proprietary API? With a custom ESP32 web server, all of that is possible. And if you're learning embedded web development, building one from the ground up is one of the best exercises you can do.

What You'll Need

For this tutorial, you'll need:

  • ESP32 DevKit or ESP32-WROOM-32 — Any variant works, though the DevKit with USB-C is the most convenient
  • Micro USB cable — For programming and power
  • LED (any color) — With a 330Ω resistor
  • DHT22 temperature and humidity sensor — Optional, for the sensor reading section
  • Breadboard and jumper wires
  • Arduino IDE or PlatformIO — We'll use Arduino IDE for simplicity

Step 1: Setting Up the Arduino IDE

If you haven't already, install the ESP32 board package in the Arduino IDE. Open File → Preferences and add this URL to the "Additional Board Manager URLs" field:

https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

Then go to Tools → Board → Board Manager, search for "ESP32," and install the package by Espressif Systems. Once installed, select your board from Tools → Board → ESP32 Arduino → ESP32 Dev Module.

Step 2: The Basic Web Server Skeleton

Let's start with the simplest possible ESP32 web server. This sketch creates a Wi-Fi access point and serves a single HTML page when you connect to it:

#include <WiFi.h>
#include <WebServer.h>

// Replace with your network credentials
const char* ssid = "ESP32_AP";
const char* password = "12345678";

WebServer server(80);

void setup() {
  Serial.begin(115200);
  
  // Create Wi-Fi access point
  WiFi.softAP(ssid, password);
  Serial.print("IP Address: ");
  Serial.println(WiFi.softAPIP());

  // Handle root page
  server.on("/", HTTP_GET, []() {
    server.send(200, "text/html",
      "<html><body><h1>ESP32 Web Server</h1>"
      "<p>Hello from ESP32!</p></body></html>"
    );
  });

  server.begin();
}

void loop() {
  server.handleClient();
}

Upload this sketch, then connect your phone or laptop to the Wi-Fi network named "ESP32_AP" with password "12345678." Open a browser and navigate to 192.168.4.1. You should see your message displayed on the page. Congratulations — you've just built a web server on a $5 chip.

Step 3: Controlling an LED Over the Web

Now let's make it actually useful. We'll add buttons to turn an LED on and off. Wire the LED's longer leg (anode) to GPIO 2 through the 330Ω resistor, and the shorter leg (cathode) to GND.

Here's the complete sketch with LED control:

#include <WiFi.h>
#include <WebServer.h>

const char* ssid = "ESP32_AP";
const char* password = "12345678";

WebServer server(80);

const int ledPin = 2; // Built-in LED on most ESP32 DevKits

void setup() {
  Serial.begin(115200);
  pinMode(ledPin, OUTPUT);
  
  WiFi.softAP(ssid, password);
  Serial.print("IP Address: ");
  Serial.println(WiFi.softAPIP());

  // HTML page with ON/OFF buttons
  server.on("/", HTTP_GET, []() {
    String html = R"=====(
      <!DOCTYPE html>
      <html>
      <head>
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <style>
          body { font-family: Arial; text-align: center; margin-top: 50px; }
          .btn { padding: 15px 32px; font-size: 18px; margin: 5px; cursor: pointer; }
          .on { background-color: #4CAF50; color: white; border: none; }
          .off { background-color: #f44336; color: white; border: none; }
          .status { font-size: 24px; margin: 20px; }
        </style>
      </head>
      <body>
        <h1>ESP32 LED Control</h1>
        <p class="status">LED is <span id="status">OFF</span></p>
        <button class="btn on" onclick="ledOn()">ON</button>
        <button class="btn off" onclick="ledOff()">OFF</button>
        <script>
          function ledOn() {
            fetch('/led/on').then(r => location.reload());
          }
          function ledOff() {
            fetch('/led/off').then(r => location.reload());
          }
        </script>
      </body>
      </html>
    )=====";
    server.send(200, "text/html", html);
  });

  // LED ON endpoint
  server.on("/led/on", HTTP_GET, []() {
    digitalWrite(ledPin, HIGH);
    server.send(200, "text/plain", "LED ON");
  });

  // LED OFF endpoint
  server.on("/led/off", HTTP_GET, []() {
    digitalWrite(ledPin, LOW);
    server.send(200, "text/plain", "LED OFF");
  });

  server.begin();
}

void loop() {
  server.handleClient();
}

The key here is the server.on() function, which registers callback handlers for specific URL paths. When you visit /led/on, the ESP32 sets the GPIO pin HIGH and returns a plain text response. The HTML page uses the fetch() API to make requests without refreshing, making the interface feel snappy and responsive.

Step 4: Reading Sensor Data in Real Time

Controlling an LED is just the beginning. Let's add a DHT22 sensor and display the readings on our web page. Connect the DHT22's DATA pin to GPIO 4, VCC to 3.3V, and GND to GND. You'll also need the DHT sensor library by Adafruit — install it from the Arduino Library Manager.

#include <WiFi.h>
#include <WebServer.h>
#include <DHT.h>

const char* ssid = "ESP32_AP";
const char* password = "12345678";
WebServer server(80);

#define DHTPIN 4
#define DHTTYPE DHT22
DHT dht(DHTPIN, DHTTYPE);

const int ledPin = 2;

void setup() {
  Serial.begin(115200);
  dht.begin();
  pinMode(ledPin, OUTPUT);
  
  WiFi.softAP(ssid, password);
  Serial.println(WiFi.softAPIP());

  server.on("/", HTTP_GET, []() {
    float temp = dht.readTemperature();
    float hum = dht.readHumidity();

    String html = R"=====(
      <!DOCTYPE html>
      <html>
      <head>
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <style>
          body { font-family: Arial; text-align: center; margin-top: 50px; }
          .card { background: #f0f0f0; padding: 20px; border-radius: 10px; display: inline-block; margin: 10px; }
          h2 { color: #333; }
          .value { font-size: 36px; font-weight: bold; color: #2c3e50; }
          .unit { font-size: 18px; color: #666; }
          .btn { padding: 15px 32px; font-size: 18px; margin: 10px; cursor: pointer; border: none; }
          .on { background-color: #4CAF50; color: white; }
          .off { background-color: #f44336; color: white; }
        </style>
      </head>
      <body>
        <h1>🌡️ ESP32 Sensor Dashboard</h1>
        <div class="card">
          <h2>Temperature</h2>
          <p class="value">%%TEMP%%<span class="unit">°C</span></p>
        </div>
        <div class="card">
          <h2>Humidity</h2>
          <p class="value">%%HUM%%<span class="unit">%</span></p>
        </div>
        <br>
        <button class="btn on" onclick="ledOn()">LED ON</button>
        <button class="btn off" onclick="ledOff()">LED OFF</button>
        <br>
        <p>Refresh page for updated readings.</p>
        <script>
          function ledOn() { fetch('/led/on'); }
          function ledOff() { fetch('/led/off'); }
        </script>
      </body>
      </html>
    )=====";
    
    html.replace("%%TEMP%%", isnan(temp) ? "--" : String(temp, 1));
    html.replace("%%HUM%%", isnan(hum) ? "--" : String(hum, 1));
    server.send(200, "text/html", html);
  });

  server.on("/led/on", HTTP_GET, []() {
    digitalWrite(ledPin, HIGH);
    server.send(200, "text/plain", "ON");
  });
  server.on("/led/off", HTTP_GET, []() {
    digitalWrite(ledPin, LOW);
    server.send(200, "text/plain", "OFF");
  });

  server.begin();
}

void loop() {
  server.handleClient();
}

The String.replace() trick lets you embed dynamic values into the HTML template before sending it. This is a lightweight approach that works well for simple dashboards. For more complex applications, consider returning JSON data from a dedicated API endpoint and updating the page with JavaScript.

Step 5: Connecting to Your Home Wi-Fi

So far we've been using the ESP32 as an access point, which means your devices connect directly to the ESP32. But you can also connect the ESP32 to your existing home network, letting you access the web server from any device on your Wi-Fi without switching networks:

const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";

Replace the WiFi.softAP() call with:

WiFi.begin(ssid, password);
while (WiFi.status() != WL_CONNECTED) {
  delay(500);
  Serial.print(".");
}
Serial.println("");
Serial.println("WiFi connected");
Serial.print("IP Address: ");
Serial.println(WiFi.localIP());

After uploading, open the Serial Monitor at 115200 baud. Once connected, it will print the ESP32's IP address on your local network. Type that IP into any browser on your network, and you'll see your dashboard.

Step 6: Adding AJAX for Real-Time Updates

The pages we've built so far require a manual refresh to get new sensor data. Let's fix that with AJAX polling, which fetches fresh data in the background every few seconds:

<script>
  setInterval(() => {
    fetch('/sensor')
      .then(r => r.json())
      .then(data => {
        document.getElementById('temp').innerText = data.temp + '°C';
        document.getElementById('hum').innerText = data.hum + '%';
      });
  }, 3000); // Update every 3 seconds
</script>

And add this endpoint on the ESP32 side:

server.on("/sensor", HTTP_GET, []() {
  float temp = dht.readTemperature();
  float hum = dht.readHumidity();
  String json = "{\"temp\":" + String(temp, 1) + ",\"hum\":" + String(hum, 1) + "}";
  server.send(200, "application/json", json);
});

Now your dashboard updates automatically without any page refreshes. This pattern is the foundation of every modern IoT dashboard.

Troubleshooting Common Issues

If your ESP32 web server isn't responding, here are the most common causes:

Can't connect to Wi-Fi: Double-check your SSID and password. Make sure the ESP32 is within range of your router. If using AP mode, make sure you're connecting to the ESP32's network, not your regular Wi-Fi.

Page loads but controls don't work: Verify the correct GPIO pin in your code matches your actual wiring. Remember that ESP32 pins are numbered differently than the physical pin numbers on the board.

Sensor readings are NaN: Check your wiring connections and make sure the DHT22's data pin matches the pin number in your code. Give the sensor a few seconds to initialize after power-on.

Web page is slow to respond: The ESP32 handles one request at a time. Avoid long-running operations in your request handlers. For high-frequency data, use AJAX polling rather than page refreshes.

Conclusion

Building an ESP32 web server is one of the most rewarding beginner projects because the results are immediately tangible — you can open a web browser and see your hardware respond in real time. You've learned the core concepts of handling HTTP requests, serving HTML, processing form inputs, and serving JSON data. These same patterns apply whether you're building a simple LED controller or a full home automation dashboard.

The best part? The entire thing runs locally on a $5 chip with no cloud dependencies, no subscription fees, and no privacy concerns. Your data never leaves your network. That's the DIY maker ethos at its finest.
