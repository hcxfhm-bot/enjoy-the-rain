How to Build a DIY Smart Doorbell with Raspberry Pi and Home Assistant

📅 July 30, 2026 ⏱️ 14 min read ✍️ 3D Print Starter Team
🔔

Store-bought smart doorbells like Ring or Nest cost $100-$250 — and that's before the optional monthly subscription for cloud storage. If you already have a Raspberry Pi sitting around and want full control over your data, building a DIY smart doorbell is surprisingly straightforward. You get video streaming, motion alerts, two-way audio, and tight Home Assistant integration — all running locally with zero subscription fees.

This guide walks you through building a complete smart doorbell system using a Raspberry Pi, a camera module, and free open-source software. Total cost: under $50 if you reuse old parts, or around $70-80 for a fresh build.

If you're new to Raspberry Pi projects, check out our 10 Raspberry Pi DIY Projects for Beginners guide for foundational setup tips before diving in.

What You'll Build

By the end of this project, your DIY smart doorbell will include:

  • HD video streaming — Live view through Home Assistant or any browser
  • Motion detection — Get alerts when someone approaches your door
  • Two-way audio — Talk to visitors from your phone
  • Local video storage — Save clips to NAS, microSD, or network storage
  • Home Assistant integration — Trigger automations, lights, and more
  • Optional: 3D-printed enclosure — A custom case that looks professional

Components You Need

Here's the hardware list for a complete DIY smart doorbell:

  • Raspberry Pi Zero 2 W or Raspberry Pi 3/4 — Zero 2 W is ideal for low power consumption
  • Raspberry Pi Camera Module — HQ Camera for better quality, or the standard v2 for budget builds
  • Wide-angle lens (optional) — 160° or 180° lens for better doorframe coverage
  • USB microphone or IO-HighPi add-on board — For two-way audio
  • 5V 2A power supply — Stable power is critical for reliability
  • MicroSD card — 16GB minimum, 32GB recommended
  • Doorbell transformer (optional) — If integrating with existing doorbell wiring
  • 3D-printed enclosure — Or a waterproof junction box

If you want to integrate this with existing smart home ecosystems, you'll also need a MQTT broker set up. See our guide on setting up an MQTT broker for Home Assistant for the details.

Software Options

There are several solid open-source options for running a video doorbell on Raspberry Pi. Here are the main contenders:

Option 1: Frigate NVR (Recommended for Home Assistant Users)

Frigate is a dedicated NVR (Network Video Recorder) built specifically for Home Assistant. It runs as a Docker container, handles motion detection locally using OpenCV, and integrates seamlessly with Home Assistant's entity system.

Key features:

  • AI-powered person/vehicle/animal detection (with Coral TPU accelerator)
  • Sub-500ms motion-to-alert latency
  • Home Assistant notifications with snapshot thumbnails
  • Frigate Proxy integration for live view in Home Assistant
  • Recordings stored locally, accessible anytime

Option 2: motionEyeOS

motionEyeOS is a purpose-built Linux distro for security cameras. Flash it to an SD card, configure through a web interface, and you're done. Simpler than Frigate but less integrated with Home Assistant.

Option 3: RTSP + Generic Camera Platform

For maximum flexibility, stream video via RTSP from the Pi and connect to Home Assistant using the Generic Camera integration or ESP32-CAM with custom firmware.

If you're using an ESP32-CAM module instead of a Raspberry Pi Camera, check out our guide on building a smart security camera with ESP32-CAM — the same concepts apply.

Step 1: Install Raspberry Pi OS

Start with a fresh Raspberry Pi OS Lite (or full) installation. If you need help with initial setup, our Home Assistant on Raspberry Pi guide covers the basics of flashing OS, enabling SSH, and configuring Wi-Fi.

For the doorbell, enable the camera interface:

sudo raspi-config
# Navigate to: Interface Options → Camera → Enable
# Save and reboot

For Raspberry Pi Zero, you'll need to connect the camera via the dedicated flat flex cable — be careful when inserting it, as the connectors are delicate.

Step 2: Install Frigate

Frigate runs as a Docker container alongside Home Assistant (or on a separate machine if you prefer). Here's the quick setup:

# Install Docker if not already installed
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# Create Frigate config directory
sudo mkdir -p /opt/frigate
cd /opt/frigate

# Create docker-compose.yml
sudo nano docker-compose.yml

Add this configuration:

version: '3.8'
services:
  frigate:
    container_name: frigate
    image: ghcr.io/blakeblackshear/frigate:stable
    shm_size: '64mb'
    volumes:
      - ./config.yml:/config/config.yml
      - /path/to/storage:/media/frigate
    ports:
      - "5000:5000"
      - "8554:8554"
    environment:
      FRIGATE_RTSP_PASSWORD: "your-secure-password"

Create the config file with your camera settings, then start Frigate:

docker-compose up -d

Step 3: Configure Your Camera

In your Frigate config.yml, add your Raspberry Pi camera:

cameras:
  doorbell:
    ffmpeg:
      inputs:
        - path: rtsp://127.0.0.1:8554/stream
          roles:
            - detect
            - record
    detect:
      enabled: true
      width: 1280
      height: 720
    record:
      enabled: true
      retain:
        days: 7
        mode: motion
    snapshots:
      enabled: true
      retain:
        default: 7
    motion:
      mask:
        - "0,0,0,800,1280,800,1280,0"

If using the Raspberry Pi Camera Module via RTSP, you'll need to install an RTSP server on the Pi. The rtsp-simple-server or RPi Camera RTSP projects handle this well.

Step 4: Add Two-Way Audio

For two-way audio, you need a microphone and speaker connected to your Raspberry Pi. The simplest approach is a USB sound card with a microphone jack, or the ReSpeaker USB Mic Array for better audio quality.

Configure audio in Frigate:

snapshots:
  enabled: true
  audio:
    enabled: true
    threshold: 0.005
    volume_scale: 2.0

For two-way communication, Frigate supports this through its web interface — visitors can press a "Talk" button in the live view, and audio plays through your Pi's speaker.

Step 5: Connect to Home Assistant

Frigate integrates with Home Assistant through the native integration or HACS integration. Once connected, you'll see:

  • Camera entities — Live view in Home Assistant dashboards
  • Motion sensors — Trigger automations when movement is detected
  • Binary sensors — Person/vehicle/animal detection states
  • Services — Record on demand, go fullscreen, snapshot

Create automations in Home Assistant for common scenarios:

automation:
  - alias: Doorbell Motion - Turn On Porch Light
    trigger:
      platform: state
      entity_id: binary_sensor.doorbell_person
      to: 'on'
    action:
      service: switch.turn_on
      target:
        entity_id: switch.porch_light

  - alias: Doorbell Press - Announce in Home
    trigger:
      platform: mqtt
      topic: home/doorbell/ring
    action:
      service: notify.mobile_app_your_phone
      data:
        message: "Someone is at the door!"
        data:
          priority: high
          ttl: 0

If you're new to Home Assistant automations, our Home Assistant Automations for Beginners guide covers the basics of triggers, conditions, and actions.

Step 6: Build or Print the Enclosure

A clean enclosure keeps your doorbell protected from weather and looks professional. You have two options:

3D Printed Enclosure (Recommended)

Design or download a weatherproof case for your Raspberry Pi and camera. Key design considerations:

  • Waterproof rating — IP65 or higher for outdoor use
  • Lens opening — Precisely sized for your camera module or lens
  • Ventilation — Small vents to prevent condensation
  • Mounting points — Keyhole slot or screw holes for wall mounting

PETG or ABS filament works best for outdoor enclosures — they're more UV and temperature resistant than PLA. See our guide on designing weatherproof outdoor sensor enclosures for detailed printing tips.

Junction Box Solution

A simple ABS waterproof junction box from the hardware store works well. Drill holes for the camera lens, USB ports for power, and mount everything inside. Sand the box flat and paint it to match your house trim.

Step 7: Power Options

How you power your doorbell depends on your setup:

Power Over Ethernet (PoE)

The cleanest solution. Use a PoE splitter or a Raspberry Pi with native PoE (Pi 3B+ or Zero W with PoE hat). Run a single Ethernet cable — no electrical wiring needed.

Doorbell Transformer

If you're replacing an existing wired doorbell, tap into the transformer wiring. Most doorbell transformers output 16-24V AC, which you'll need to convert to 5V DC using a buck converter.

# Typical wiring:
Doorbell Transformer (16-24V AC)
  → Buck Converter (to 5V DC)
  → Raspberry Pi microUSB

For smart light switch integration and wiring basics, see our guide on smart light switch wiring — the electrical principles are similar.

Battery Backup

Add a USB power bank as a UPS to keep your doorbell online during power outages. A 10,000mAh bank will run a Pi Zero 2 W for 12-18 hours.

Advanced: Add Face Recognition

Want your doorbell to know who visitors are? Add face recognition using DeepStack or TensorFlow Lite on your Raspberry Pi.

Train the model with photos of family members, then modify your automations:

automation:
  - alias: Known Visitor - Open Gate
    trigger:
      platform: state
      entity_id: sensor.front_door_recognized_face
    condition:
      - condition: state
        entity_id: sensor.front_door_recognized_face
        state: "Dad"
    action:
      service: switch.turn_on
      target:
        entity_id: switch.gate_opener

Troubleshooting Common Issues

Camera Not Detected

Check that the camera flex cable is seated properly in both connectors. On Pi Zero, ensure the silver contacts face the correct direction. Run libcamera-hello to test.

High CPU Usage

The Raspberry Pi Zero 2 W can handle one camera at 720p. If performance is sluggish, reduce resolution to 640x480 or offload detection to a Coral TPU USB stick.

Video Lag or Drops

Use a wired Ethernet connection for the doorbell Pi. WiFi on the Zero 2 W works, but interference and congestion can cause dropped frames. A PoE connection is most reliable.

Audio Not Working

Set the correct audio input device in Frigate config. USB microphones often show up as index 1. Test with arecord -l and aplay -l to confirm device numbers.

Privacy and Security Considerations

Since your doorbell is always watching, security matters:

  • Change default passwords — Every service (SSH, Frigate, MQTT) needs strong unique passwords
  • Use HTTPS — Set up Let's Encrypt for Home Assistant to encrypt all traffic
  • Firewall rules — Only allow access from your local network; never expose directly to the internet
  • Regular updates — Keep Raspberry Pi OS, Docker, and Frigate updated
  • VPN access — Use Tailscale or WireGuard for remote access without port forwarding

If you're building multiple smart devices, our guide on smart home network setup covers how to segment IoT devices from your main network for security.

Final Thoughts

A DIY smart doorbell gives you everything the commercial options offer — and more. No subscription fees, no cloud dependency, full data ownership, and the flexibility to add whatever features you want. Whether you keep it simple with motion alerts and local storage, or go all-in with face recognition and home automation triggers, the core build costs under $80 and can be assembled in an afternoon.

The hardest part is usually the physical installation: routing power, running cables, and mounting the enclosure. Once that's done, everything else is software — and with Home Assistant, you're limited only by your imagination.
